# 動作確認のテスト

ゲームをヘッドレスのブラウザ（画面を出さない Chromium）で開き、いつもの流れを自動で試す（バックログ B012）。

## 流し方

```bash
cd tests
npm install        # 初回だけ
npm run setup      # 初回だけ。テスト用のブラウザを入れる
npm test
```

全部通ると「全部 OK（7 個）」と出る。失敗すると「×」の行に、どこで止まったかが出る。サーバーはテストが自分で立てるので、`python3 -m http.server` はいらない。

## 試していること（smoke.mjs）

1. 起動するとタイトル画面が出る
2. タイトル → キャラ選択 → 最初の攻撃選び → プレイ
3. ポーズすると時間が止まり、もう一度押すと再開する
4. ポーズメニューの「タイトルへ戻る」でタイトルに戻る
5. ゲームオーバーからやり直せる
6. 豆コインでキャラ（品種）を買える（`?coins=500`）
7. 1 面をクリアして、E キーでエクストラステージに進める（`?boss`）

どのテストも、コンソールにエラーが出たら失敗にする。ゲームは `?test` を付けて開き、`window.game`（`src/main.js`）から今の画面などを見る。
