# 動作確認のテスト

ゲームを画面なしのブラウザ（ヘッドレス Chromium）で開き、いつもの操作と主な機能が動くこと、コンソールにエラーが出ないことを確かめる（バックログ B012）。
ゲーム本体はビルド不要・外部ライブラリなしのまま（憲法 II）。テストだけが Playwright を使う。

## 使い方

```bash
npm --prefix tests install                    # 初回だけ
npx --prefix tests playwright install chromium   # ブラウザが入っていないときだけ
npm --prefix tests test
```

サーバーはテストが自分で立てるので、`python3 -m http.server` は要らない。全部通ると「すべて通った」と出て、1 つでもうまくいかないと「✕」の行と理由が出る。

## 確かめること

1. 起動するとタイトル画面が出る
2. キャラ選択 → 最初の攻撃を選ぶ → プレイが始まる
3. WASD と矢印キーで動く
4. Esc と P でポーズ・再開できる
5. やられたあと、結果画面からやり直せる
6. 自分の記録が保存され、開き直すとタイトルに出る
7. 豆コインでキャラを買える（`?coins=500`）
8. ボスを倒すとクリアになり、E でエクストラステージに進める
9. MAX の武器 2 つずつで 5 秒遊んでもエラーが出ない

新しい機能を足したら、`run.mjs` に `check(...)` を 1 つ足す。
