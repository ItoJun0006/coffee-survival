# 珈琲サバイバル

珈琲をテーマにしたサバイバルゲーム。PC のブラウザで遊ぶ HTML5 Canvas ゲーム。

## 構成

ビルド不要。素の JavaScript (ES Modules) と Canvas 2D で動作する。

```
index.html             エントリポイント
css/style.css          全画面表示のスタイル
src/main.js            起動処理
src/game.js            ゲームループ・描画・状態管理
src/input.js           キーボード / マウスクリック入力
src/config.js          ゲームバランス・色・文言などの定数（調整する数値はここに集める）
src/entities/          プレイヤー・敵・ボス・豆・経験値の粒など
src/weapons/           攻撃（武器）10 種類と、Lv ごとの強化・MAX の見た目
src/characters.js      キャラ（品種 × 焙煎度と特別なキャラ）
src/progress.js        ポイントカード・キャラの解放・豆コインの保存
src/records.js         自分の記録（自己ベスト）の保存
assets/                画像・フォント・アイコン
specs/                 仕様書（spec-kit）とバックログ
```

## 起動

ES Modules を使うため、ファイルを直接開くのではなくローカルサーバ経由で開く。

```bash
python3 -m http.server 8000
```

http://localhost:8000 を開く。

## 操作

| 操作 | キー |
| --- | --- |
| スタート | Space / Enter / クリック |
| キャラ選択 | ←→↑↓（WASD）で選んで Space / Enter。クリックで選び、もう一度クリックで決定。ホイールでスクロール。鍵のキャラは決定すると、解放条件か、豆コインで買うメニューが出る。Q で椿のスキンを着る / 脱ぐ（着られるキャラだけ）。Esc でタイトルへ |
| 最初の攻撃選び | ランダムな 3 枚から ←→ で選んで Space / Enter、1〜3 キー、またはクリック（散弾ロブスタは選ばずに豆ショットガンで始まる） |
| 移動 | WASD / 矢印キー |
| レベルアップの攻撃選び | ←→ で選んで Space / Enter、1〜3 キー、またはクリック |
| ポーズ | Esc / P |
| 音の消音 / 解除 | M |
| 音楽の音量 | − で下げる / ＋ で上げる（ポーズメニューの「音楽の音量」でも変えられる） |
| ポーズメニューの選択 | ↑↓（W / S）で選んで Space / Enter、またはクリック |
| リトライ | Space / Enter / クリック |
| エクストラステージへ | 1 面をクリアした画面で E。持っていく攻撃を 1 つ選ぶ |

## ルール

時間とともにカフェインが減っていく。マップ上の珈琲豆を拾って補給し、できるだけ長く生き延びる。

10 分たつと眠気の化身（ボス）が現れ、倒すと朝が来てクリア。敵が落とす経験値の粒でレベルが上がるたびに、攻撃（最大 3 つ）か強化アイテム（最大 2 種類）を選んで強くする。それぞれ最大 Lv 8。

最初の攻撃は、ランダムに出る 3 枚のカードから選ぶ。

### 豆コインとキャラ

1 回遊ぶごとに、生き延びた時間・倒した敵の数・クリアに応じて豆コインがたまる（結果画面で数え上げる）。豆コインで新しいキャラ（品種）を買える。条件を満たすと解放されるキャラもいる。今持っている豆コインは、タイトル画面とキャラ選択画面に出る。

### エクストラステージ

1 面をクリアしたあと、攻撃を 1 つだけ持って挑戦する 2 つ目のステージ。マップは狭く、敵は 1 面の 8:00 ごろの続きの強さで始まる。カフェインは時間で減らない代わりに、レベルアップのたびに少し回復する。攻撃とアイテムは、Lv 8 を超えて Lv 16 まで強くできる（限界突破。候補に出るのはレベルアップのたびに 20% の確率）。

### 自分の記録

1 面のプレイの、最長生存時間・1 回で倒した敵の最多数・最高到達レベルとクリア回数を、遊んでいるブラウザに保存する。結果画面とタイトル画面に出る。エクストラステージと、確認用の URL パラメータで始めたプレイは数えない。

## 確認用の URL パラメータ

動作確認のために、URL の後ろに付けて開く（例：http://localhost:8000/?weapons=mill:8,ice:5）。`?unlockAll`・`?coins` を付けると、キャラの解放と豆コインは保存されない。どれを付けても、自分の記録には数えない。

| パラメータ | 内容 |
| --- | --- |
| `?weapons=mill:8,drip:5` | 指定した攻撃を、指定した Lv で持って始まる（攻撃の枠 3 つまで。最初の攻撃は選ばない） |
| `?level=N` | レベル N から始まる（まだ持っていない攻撃を優先して自動で選ぶ） |
| `?boss` | ボスが出る直前（9:57）から始まる |
| `?unlockAll` | すべてのキャラを解放済みとして扱う |
| `?coins=N` | 豆コインを N 枚持った状態で始まる |

攻撃の id：`beanGun`（豆マシンガン）・`beanShotgun`（豆ショットガン）・`mill`（ミル・トルネード）・`mug`（マグカップ投げ）・`drip`（ドリップの雨）・`steam`（スチーム噴射）・`puddle`（こぼれ珈琲）・`ice`（アイス珈琲）・`espresso`（エスプレッソ・ショット）・`shockwave`（カフェイン・ショックウェーブ）
