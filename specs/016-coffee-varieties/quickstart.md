# Quickstart: 品種と豆コインを確かめる

## 準備

```bash
python3 -m http.server 8000
```

PC のブラウザ（幅 1000px 以上）で開く。ファイルを変えたあとは、強制再読み込みをする。
`?unlockAll`・`?coins=N` を付けて開いた間は、記録を保存しない。

## 1. 66 体の並びと見た目（US1）

1. `http://localhost:8000/?unlockAll` を開き、キャラ選択画面に進む。
2. 66 マスが 6 列で並び、「？？？」がない。1 段目はアラビカ 浅・中・深、リベリカ大粒、散弾ロブスタ、赤ちゃん豆。2 段目から 1 段に 2 品種ずつ（SC-001）。
3. 下までスクロールし、同じ品種の 3 体は同じ模様で、焙煎度が深いほど色が濃い。浅煎りでも模様が見える（SC-002）。
4. 品種を選ぶと、右側に特徴の一言・性能のバー・特別な力の名前と効果が出る。品種ごとに違う（SC-003）。

## 2. 特別な力（US1）

`?unlockAll` で次の品種を選んで遊び、違いを確かめる。

| 品種 | 確かめること |
| --- | --- |
| ブルボン | 珈琲豆を拾うと、ふつうより多く回復する |
| モカ | 経験値の粒が遠くから吸い寄せられる |
| マンデリン | 攻撃を受けたあと、点滅している時間が長い |
| ムンドノーボ | カフェインの減りが遅い |
| カトゥーラ | 動いている間、攻撃の間隔が短い |
| キリマンジャロ | 止まっている間、敵が早く倒れる |

開発者ツールのコンソールで、ゲームの値（`game.player.invincibleSec` など）を見てもよい。

## 3. 豆コインがたまる・保存される（US2）

1. パラメータなしで開き、タイトル画面の左下に「豆コイン N 枚」が出ている。
2. 1 回遊んでゲームオーバーになる。結果画面で、内わけ（生き延びた時間・倒した敵）が順に数え上がり、合計に足される。
3. もう一度遊び、数え上げの途中で Space を押す：すぐ合計になり、やり直しにはならない。もう一度押すとやり直す。
4. ページを開き直し、タイトルの豆コインが増えたままになっている。
5. `?boss` で始めてボスを倒す：クリアの行（＋30）も出る。明るい背景でも内わけが読める。
6. ポーズから「タイトルへ戻る」でやめたときは、豆コインは増えない。

## 4. 品種を買う（US2）

1. `?coins=120` で開き、キャラ選択画面へ。鍵の品種のマスの下に値段が出て、買える品種（ブルボン・ティピカ・カトゥーラ・モカ）の鍵は金色。
2. モカのマスで決定：メニュー風のポップアップに、品種名・由来・3 体・特別な力・値段の札（100 枚）・持っている 120 枚が出る。
3. ←→ で「注文する」を選んで決定：「新しい品種『モカ』が解放された！（浅煎り・中煎り・深煎り）」と出て、モカ 中煎りが選ばれた状態になり、持っている量が 20 枚になる。
4. ゲイシャのマスで決定：3 体が影になり、「あと 980 枚」と「とじる」が出る。Esc でも閉じる。
5. 特別なキャラ（リベリカ大粒など）が鍵のときは、今までどおり解放条件が出る。

## 5. いつもの確認

- 移動・ポーズと再開・リトライが動く。エクストラステージ（011）も遊べる。コンソールにエラーがない。
- 確かめるときに `localStorage` を変えたら、元に戻す。
