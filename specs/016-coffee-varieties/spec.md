# Feature Specification: 珈琲豆の品種を増やしてキャラを 66 体にする

**Feature Branch**: `characters-66`

**Created**: 2026-10-22

**Status**: Implemented

**Input**: User description: "キャラクターを最終目標の 66 体まで、設定から生成できるようにする。仕様 001（FR-080〜FR-090）に合わせる"

## Clarifications

### Session 2026-10-22

- Q: 品種の差は、性能の倍率だけにするか、品種ごとの特別な力も付けるか、最初の武器も変えるか？ → A: 性能の倍率に加えて、品種ごとに特別な力を 1 つずつ持たせる
- Q: 品種の解放のしかたは、記録が決めた値に届いたら解放するか、順番制にするか、ためた通貨で買うか？ → A: 遊んでためた通貨で買って解放する（specs/ideas.md の 3）
- Q: 記録（最長生存時間など）は、キャラごとに分けるか？ → A: 分けない。今までどおりキャラに関係なく 1 つにまとめる
- Q: 通貨の名前は？ → A: 豆コイン
- Q: 品種をすべてそろえるまでの目安は？ → A: 約 12 時間（1 回のプレイで平均 80 枚前後たまり、約 65 回で全品種の合計 5,190 枚に届く）
- Q: 品種の値段の決め方は？ → A: 品種ごとに決まった値段で、好きな順に買える。ブルボン 50 枚から 20 枚ずつ上がってブルーマウンテン 400 枚、ゲイシャは特別に 1,000 枚
- Q: 品種の見た目は？ → A: 3 案（形と大きさ・割れ目／豆の上の模様／頭や首の飾り）から「豆の上の模様」に決めた。豆の形と大きさは今のまま、品種ごとに決まった模様と色を豆の上に描く
- Q: 品種を買うポップアップの見た目は？ → A: 3 案（今のポップアップを広げる／喫茶店のメニュー風／ポイントカード風）から「喫茶店のメニュー風」に決めた。生成りの紙に品種名・由来・浅煎り・中煎り・深煎りの 3 体・特別な力を並べ、右下に値段の札を出す。足りないときは 3 体を影で出す
- Q: 結果画面の豆コインの見た目は？ → A: 3 案（1 行で出す／内わけを数え上げる／次の品種までの残りを出す）から「内わけを数え上げる」に決めた。内わけの行が順に出て数字が数え上がり、最後に合計に足される。Space / Enter / クリックで数え上げを飛ばせる

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 66 体のキャラが並び、品種ごとに違う遊び心地で遊べる（Priority: P1）

キャラ選択画面に 66 体のキャラが並ぶ。キャラは 21 の品種 × 3 つの焙煎度（63 体）と、条件で解放される特別なキャラ 3 体（リベリカ大粒・散弾ロブスタ・赤ちゃん豆）でできている。
同じ焙煎度でも、品種によって性能の得意・苦手と特別な力が違い、見た目でも品種が分かる。「？？？」のマスはなくなる。

**Why this priority**: この機能の中心。001 で約束した「66 体くらいを目標」を、中身のあるキャラでうめる。

**Independent Test**: 確認用の方法ですべてを解放した状態でキャラ選択画面を開き、66 マスすべてに名前・見た目・性能・特別な力があり、品種ごとに違うことで確認できる。

**Acceptance Scenarios**:

1. **Given** キャラ選択画面, **When** マスを見る, **Then** 66 マスが 6 列・11 段で並び、「？？？」のマスはない
2. **Given** キャラ選択画面, **When** 1 段目を見る, **Then** アラビカの浅煎り・中煎り・深煎りと、リベリカ大粒・散弾ロブスタ・赤ちゃん豆が並ぶ。2 段目からは、1 段に 2 品種ずつ（浅煎り・中煎り・深煎りの順）並ぶ
3. **Given** 解放済みの 2 つの品種の中煎り, **When** 選んで見比べる, **Then** 名前・特徴の一言・性能のバー・特別な力の説明が違う
4. **Given** 同じ品種の浅煎り・中煎り・深煎り, **When** 見比べる, **Then** 品種の見た目（形・模様など）と特別な力は同じで、焙煎度が深いほど色が濃い
5. **Given** ある品種のキャラでゲームを始める, **When** 遊ぶ, **Then** 選択画面に出ていた性能で動き、特別な力が効いている（例：珈琲豆で回復する量が多い）

---

### User Story 2 - 遊んで豆コインをため、品種を買って解放する（Priority: P2）

ゲームオーバーやクリアのたびに、遊んだ結果に応じて豆コインがたまる。キャラ選択画面で鍵の品種を選ぶと値段が出て、足りていれば買える。
買うと、その品種の浅煎り・中煎り・深煎りの 3 体がまとめて使えるようになる。品種は好きな順に買える。あとのほうの品種ほど高く、ゲイシャは特別に高額（1,000 枚）になる。

**Why this priority**: キャラを集める楽しみと、繰り返し遊ぶ目標を作る。P1 の 66 体がそろってからでよい。

**Independent Test**: 確認用の方法で豆コインを値段の直前まで持たせてから 1 回遊び、結果画面でたまった量が出て、キャラ選択画面でその品種を買うと 3 体が選べるようになることで確認できる。

**Acceptance Scenarios**:

1. **Given** プレイ中, **When** ゲームオーバーかクリアになる, **Then** 結果画面に、内わけ（生き延びた時間 ＋50・倒した敵 ＋25・ボスを倒した ＋30）の行が順に出て数え上がり、最後に今の合計（「豆コイン 340 枚（＋105）」）が出る。数え上げの途中で Space / Enter / クリックを押すと、すぐ最後の表示になる
2. **Given** タイトル画面, **When** 画面を見る, **Then** ポイントカードの表示（001 の FR-066）の近くに、「豆コイン 340 枚」のように、今持っている量が出る
3. **Given** キャラ選択画面で鍵の品種のマス, **When** 選んで Space / Enter を押すかクリックする, **Then** ポップアップに品種名・特別な力・値段・今持っている量が出る。喫茶店のメニュー風の紙に、品種名・由来・浅煎り・中煎り・深煎りの 3 体・特別な力・値段の札が出る。足りていれば「注文する」「やめる」を選べ、足りなければ 3 体が影になり、「あと 120 枚」のように足りない量が出る
4. **Given** ポップアップで「注文する」, **When** 決める, **Then** 豆コインが値段の分だけ減り、「新しい品種『ブルボン』が解放された！（浅煎り・中煎り・深煎り）」と出て、その 3 体がすぐ選べる
5. **Given** ポップアップ, **When** Esc を押すか「やめる」「とじる」を選ぶ, **Then** 何も買わずに閉じる
6. **Given** 特別なキャラ（リベリカ大粒など）が鍵, **When** 選んで決定する, **Then** 今までどおり解放条件が出る（豆コインでは買えない）

---

### Edge Cases

- 001 の FR-087 の特別なキャラ 3 体（リベリカ大粒・散弾ロブスタ・赤ちゃん豆）は、名前・性能・解放条件を変えない。品種の倍率と特別な力は、特別なキャラには付けない。
- アラビカは基準の品種で、倍率はすべて 1 倍、特別な力はない（001 の FR-083 の表のまま）。
- スキン「椿」（010）は、今までどおりアラビカの 3 体だけに付けられる。
- 前回選んだキャラは今までどおり覚えておく。覚えていたキャラが使えない場合は、アラビカの中煎りを選んだ状態にする（001 の Edge Cases）。
- ポーズから「タイトルへ戻る」でやめたプレイでは、豆コインはたまらない（001 の記録と同じく、途中でやめたものは結果ではないため）。
- 記録を保存できないブラウザの設定でも遊べる。その場合、豆コインと買った品種はページを開いている間だけ有効になる（001 と同じ）。
- 豆コインの量に上限は設けない。品種をすべて買ったあとも、豆コインはたまり続ける。
- この機能より前に遊んでいた人の記録（ポイントカード）からは、豆コインを渡さない。すべての人が 0 から始める。
- 性能の倍率を掛けた値が、性能のバーの範囲を超えるときは、バーをいっぱいにして表示する。バーの範囲は、66 体の値がほとんど範囲の中に入るように決める。
- 特別な力が、同じ種類の強化アイテム（006）と重なるときは、両方の効果を足す。攻撃の間隔は、今までどおり下限（元の 0.3 倍）より短くしない。
- 解放の知らせが、レベルアップの選択画面やポーズ中に重なったときは、その画面が閉じてから出す。

## Requirements *(mandatory)*

### Functional Requirements

**66 体の構成**

- **FR-002**: 品種は、実在する珈琲豆の品種や産地にちなむ名前にしなければならない（憲法 IV）。キャラの名前は「品種名 焙煎度」（例：「ブルボン 深煎り」）とする。品種の一覧は次のとおり。並びは、選択画面に並べる順で、2 番目からは値段の安い順でもある。

- **FR-003**: 品種・焙煎度・特別なキャラ・特別な力・豆コインの中身（名前・特徴・性能・見た目・値段・たまり方・解放条件）は、設定ファイルにまとめ、設定に品種を 1 つ書き足すだけで、3 体のキャラが選択画面に加わるようにしなければならない（憲法 III）。

**性能と特別な力**

- **FR-004**: キャラの性能は、焙煎度の性能（001 の FR-083 の表）に、品種ごとの「得意・苦手」の倍率（移動の速さ・カフェイン上限・攻撃力・攻撃の間隔）を掛けて決めなければならない。倍率は、どれも 0.85〜1.15 倍の範囲にする。
- **FR-005**: アラビカ以外の品種は、次の特別な力のうち 1 つを持たなければならない。力の強さは、同じ種類なら品種によらず同じとする。値は初期案で、遊んで調整する。

| 特別な力 | 効果 |
| --- | --- |
| 豆の回復アップ | 珈琲豆を拾ったときに回復するカフェインが 3 割増える |
| 吸い寄せ | 経験値の粒を吸い寄せ始める距離が 6 割のびる |
| 無敵時間アップ | 攻撃を受けたあとの無敵時間が 0.6 秒から 1 秒になる |
| 省エネ | カフェインが時間で減る速さが 2 割遅くなる |
| 経験値アップ | 経験値の粒から入る経験値が 15% 増える |
| 範囲アップ | すべての弾と範囲が 1 割大きくなる |
| 走り撃ち | 動いている間は、すべての攻撃の間隔が 1 割短くなる |
| 踏ん張り | 止まっている間は、すべての攻撃のダメージが 2 割上がる |

- **FR-006**: 特別な力を持つ品種は、その分だけ倍率の合計を下げ、どの品種も強さがほぼそろうようにしなければならない（目安：「移動の速さ × カフェイン上限 × 攻撃力 ÷ 攻撃の間隔」の倍率が 0.93〜0.95 前後）。
- **FR-007**: キャラ選択画面では、今までどおり性能をバー（スピード・体力・パワー・連射）で見比べられ、品種の特徴の一言と、特別な力の名前・効果を表示しなければならない。

**見た目**

- **FR-008**: 品種ごとに見た目を変え、66 体のどれもが、選択画面のマスの大きさで見分けられるようにしなければならない（001 の FR-084）。焙煎度は今までどおり豆の色の濃さで表し、品種は豆の上に描く模様で表す。豆の形と大きさは、どの品種も今のアラビカと同じにする。模様は豆の輪郭の内側だけに描き、当たる範囲は変えない。
- **FR-009**: 品種ごとの模様は次のとおり。同じ品種の浅煎り・中煎り・深煎りは同じ模様にする。アラビカと特別なキャラ 3 体は模様を付けない（今の見た目のまま）。模様は、ほかの絵と同じくドット絵の層（008）を通す。浅煎り・中煎り・深煎りのどれでも模様がはっきり見えるようにし、浅煎りの明るい豆の色に紛れる模様は、浅煎りのときだけ濃い色で描く。

| カトゥーラ | 上と下の横の 2 本線 | SL28 | 赤い斑点 |
| モカ | そばかす | カティモール | 緑の十字 2 つ |

**豆コイン**

- **FR-010**: 遊んでためる通貨「豆コイン」を用意しなければならない（憲法 IV）。数えるときは「枚」を使う（例：「豆コイン 340 枚」）。
- **FR-011**: 豆コインは、ゲームオーバーかクリアで 1 回のプレイが終わったときに、次の合計がたまらなければならない。エクストラステージ（011）も同じ。
  - 生き延びた時間：1 分ごとに 5 枚
  - 倒した敵：100 体ごとに 1 枚
  - ボスを倒してクリア：30 枚
  - エクストラステージをクリア：40 枚
  - 1 回のプレイでたまる量は、ボスまで生き延びてクリアすると約 105 枚、平均 80 枚前後とし、品種をすべてそろえるまでの目安を約 12 時間（約 65 回）にする。値は初期案で、遊んで調整する。
- **FR-012**: 結果画面（ゲームオーバー・クリア）に、そのプレイでたまった豆コインの内わけ（生き延びた時間・倒した敵・クリア）と今の合計を、数え上げて表示しなければならない。内わけの行は順に出て、数字が 0 から数え上がり、最後に合計の欄に足される。数え上げの途中で Space / Enter / クリックを押すと、すぐ最後の表示になる（そのときはやり直しにはならない）。クリアのときの明るい背景の上でも読めるよう、内わけは暗い地のパネルの上に明るい文字で出す。タイトル画面には、ポイントカードの表示（001 の FR-066）の近くに、今持っている量（例：「豆コイン 340 枚」）を小さく表示する。
- **FR-013**: 豆コインの量と買った品種は、遊んでいるブラウザに保存し、ページを開き直しても残さなければならない（ポイントカードと同じ保存のしかた。001 の FR-090）。

- **FR-015**: キャラ選択画面で鍵の品種のマスを決定しようとしたときは、喫茶店のメニュー風のポップアップ（生成りの紙）に、品種名・由来・浅煎り・中煎り・深煎りの 3 体・特別な力・値段の札・今持っている量を表示しなければならない。足りていれば「注文する」「やめる」を ←→ とクリックで選べ、足りなければ 3 体を影で出し、足りない量と「とじる」を表示する。Esc でいつでも閉じる。

- **FR-018**: 特別なキャラ 3 体は、今までどおり 001 の FR-087・FR-091 の条件で解放し、豆コインでは買えない。

**記録**

- **FR-019**: 記録（最長生存時間・最多撃破数・最高到達レベル・クリア回数）とポイントカードは、今までどおりキャラに関係なく 1 つにまとめなければならない。

**開発用**

- **FR-020**: 動作確認用に、すべてのキャラを解放した状態で遊ぶ方法と、豆コインを決めた量だけ持った状態で始める方法を用意しなければならない（URL に `?unlockAll` / `?coins=N` を付ける。001 の FR-099 と同じ扱い）。この方法で変えた状態は保存しない。

### Key Entities

- **品種**：名前、由来（品種や産地）、特徴の一言、性能の倍率（移動の速さ・カフェイン上限・攻撃力・攻撃の間隔）、特別な力、見た目（形・大きさ・模様など）、値段、並び順
- **特別な力**：名前、効果の説明、効く仕組み（豆の回復・経験値の粒・無敵時間・カフェインの減り・経験値・範囲・攻撃の間隔・ダメージ）、強さ
- **焙煎度**：001 の FR-083 のとおり（浅煎り・中煎り・深煎りの性能と色）
- **キャラクター**：品種 × 焙煎度、または特別なキャラ。名前、性能（焙煎度 × 品種の倍率）、特別な力、見た目、解放済みかどうか
- **豆コイン**：今持っている量、たまり方（時間・撃破・クリアごとの量）
- **解放の記録・ポイントカード**：001 のものに、豆コインの量と買った品種を加える

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: すべてを解放した状態で、キャラ選択画面の 66 マスすべてに名前・見た目・性能があり、「？？？」のマスが 1 つもない。
- **SC-002**: 選択画面のマスを並べた画像で、初めて見る人が、同じ品種の 3 体を 10 秒以内に見つけられる（品種が見た目で分かる）。

## Assumptions

- 66 体の内訳は、21 の品種 × 3 焙煎度（63 体）＋ 001 の FR-087 の特別なキャラ 3 体とする。特別なキャラを増やすときは、品種の数を減らして 66 に合わせる。
- 特別なキャラの名前に使っている「リベリカ」「ロブスタ」は、品種の一覧には入れない（同じ名前のキャラが 2 つに見えないようにするため）。アラビカは豆の種類の名前で、ほかの品種はアラビカの中の品種や産地の名前だが、ゲームの中では同じ「品種」として扱う。
- 選択画面の並びは、1 段目にアラビカの 3 体と特別なキャラ 3 体、2 段目から 1 段に 2 品種ずつとする（6 列 × 11 段 ＝ 66 マス）。
- 焙煎度の性能（001 の FR-083 の表）と、性能のバーの 4 項目は変えない。バーの範囲は、66 体の値に合わせて見直してよい。
- 品種の性能の倍率・特別な力の強さ・豆コインのたまり方と値段・見た目の細かい点は、設定で調整する前提とする。初期値は [research.md](./research.md) の R2〜R4。
- 買った品種を手放して豆コインに戻すことはできない。豆コインをほかの物（強化など）に使うことは、この仕様の範囲外とする。
- 001 の Assumptions にある「キャラ用の仕様書として別に作る」は、この仕様書を指す。この仕様を実装するときに、001 の FR-082・FR-085・FR-086 と Assumptions の該当する所、specs/ideas.md の 3 を、この仕様に合わせて書き直す。
