# Data Model: 8 種類の武器に Lv ごとの強化と MAX の見た目を付ける

## 武器の設定（CONFIG.weapons.&lt;id&gt;）

今ある項目（`name`・`desc`・`element`・`intervalSec`・`damage` など）に、次を足す。書き方の約束は [contracts/weapon-upgrades.md](./contracts/weapon-upgrades.md)。

| 項目 | 内容 |
| --- | --- |
| `upgrades` | Lv（2・4・6・8）ごとの特別な強化。値は「`*Rate` はかけ算、それ以外は上書き」で重なる。各 Lv に `desc`（カードの説明）を持つ |
| `commonDesc` | 共通の強化だけが入る Lv（3・5・7）のカードの説明 |
| `commonLevels` | 共通の強化を受ける Lv。省略すると毎 Lv（8 種類はすべて省略） |
| `maxVisual` | Lv 8 の見た目の色・大きさ・数。3 案の比較中だけ `variant`（A・B・C）を持つ |
| 武器ごとの追加の値 | 例：マグの `splashRadius`、ドリップの `linger`、こぼれ珈琲の `trail`、エスプレッソの `stream`。範囲アップで大きくなる値は `areaKeys` に入れる |

## 武器の状態（Weapon）

| 項目 | 内容 | 決まり |
| --- | --- | --- |
| `level` | 1〜8 | 強化を選ぶたびに 1 上がる。8 で候補に出なくなる |
| `stats`（読み出し） | 今の Lv までの特別な強化をまとめた値 | `upgrades` を Lv の小さい順に重ねる |
| `commonUpgrades`（読み出し） | 共通の強化を受けた回数 | `commonLevels` があればその数、なければ `level − 1` |
| `damageRate`（読み出し） | ダメージの倍率 | `1 + 0.25 × commonUpgrades` |
| `intervalRate`（読み出し） | 攻撃の間隔の倍率 | キャラ × 共通の強化 × 発生頻度アップ。下限 0.3 |
| `isMax`（読み出し） | Lv 8 か | MAX の見た目を使うかどうか |

## 敵の状態（Enemy）に足すもの

| 項目 | 内容 | 決まり |
| --- | --- | --- |
| 足どめ | 遅くなる残り時間と倍率 | こぼれ珈琲 Lv 6 以降。上にいる間かけ直す。ボスには効かない |
| 凍りの待ち時間 | 凍りが解けた直後に凍らない残り時間 | 待ち時間中・凍っている間は、凍らせても変わらない |
| `thaw()` | 凍りを解く | アイス珈琲 Lv 6 以降の「砕く」で使う。解けたら待ち時間に入る |

## 状態の移り方

```text
Lv 1 ──強化──▶ Lv 2（特別）──▶ Lv 3（共通のみ）──▶ Lv 4（特別）──▶ Lv 5 ──▶ Lv 6（特別）──▶ Lv 7 ──▶ Lv 8（MAX：特別＋見た目）
                       ※ 8 種類は、どの Lv でも共通の強化も受ける

敵の凍り：通常 ──凍らせる──▶ 凍っている ──時間切れ／砕く──▶ 待ち時間（凍らない）──▶ 通常
```

## 検証のルール（仕様より）

- 攻撃の間隔は、どう重なっても元の 0.25 倍より短くしない（006 の FR-009）。
- はっきり描く部分の大きさは、当たる範囲と一致させる（002 の FR-005）。
- 同じ武器の攻撃が重なっても、1 体の敵へのダメージ・プレイヤーの回復は 1 つ分だけ（FR-014）。
- ボスは凍らない・押し返されない・足が遅くならない。
