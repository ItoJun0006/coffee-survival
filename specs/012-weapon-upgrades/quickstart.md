# Quickstart: 武器の強化と MAX の見た目を確かめる

## 準備

```bash
python3 -m http.server 8000
```

PC のブラウザ（幅 1000px 以上）で `http://localhost:8000/` を開く。ファイルを変えたあとは、強制再読み込み（キャッシュを使わない再読み込み）をする。

## 1. 武器ごとの強化（US1・SC-001）

1. `http://localhost:8000/?weapons=<id>:1` で始める（例：`?weapons=mill:1`）。
2. `?weapons=<id>:2`・`:4`・`:6`・`:8` と Lv を変えて開き直し、[spec.md](./spec.md) の FR-004〜FR-013 の表のとおりに変わるかを見る（数・大きさ・届く距離・追加の効き目・MAX の代償）。
3. Lv 3・5・7 でも、ダメージと攻撃の速さが少しずつ上がっていること（共通の強化。FR-002）。
4. レベルアップのカードで、次の Lv で変わることが説明に出ること（FR-003）。

## 2. MAX の見た目（US2・SC-002）

1. `?weapons=<id>:7` と `?weapons=<id>:8` を見比べ、Lv 8 の方がひと目で豪華に見えること。
2. はっきり描かれた部分の端と、敵に当たり始める位置が一致していること（FR-016）。
3. 経験値の粒（金色の丸）・珈琲豆・敵と見間違えないこと。

## 3. 不具合の修正（US3・FR-014）

| 武器 | 確かめること |
| --- | --- |
| ミル・トルネード | 浅煎り（攻撃間隔 ×0.75）と深煎りで、同じ敵に当たる間隔が変わる。発生頻度アップを取ると短くなる |
| こぼれ珈琲 | 立ち止まって水たまりを重ねても、敵の減り方が 1 つ分のまま |
| ラテアート | 模様が重なっても、回復の速さが 1 つ分のまま |
| こぼれ珈琲・エスプレッソ | 描かれた端と、当たり始める位置が一致する |

## 4. 重い場面（SC-004）

1. `?weapons=mill:8,ice:8,puddle:8&level=20` などで MAX の武器を 3 つ持って始め、敵が 150 体出るまで（約 8 分。ビッグウェーブ中は早い）遊ぶ。
2. カクつかないこと。開発者ツールの Performance で、1 フレームが 16.7ms 以内に収まっていること。

## 5. いつもの確認（憲法「開発の流れ」）

- 移動（WASD / 矢印）、ポーズ（Esc / P）と再開、ゲームオーバー後のリトライが動く。
- コンソールにエラーが出ていない。
