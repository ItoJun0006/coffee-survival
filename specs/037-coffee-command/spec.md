# Feature Specification: 隠しコマンド「COFFEE」でカフェオレ色の豆になる

**Feature Branch**: `feature/037-coffee-command`

**Created**: 2026-10-24

**Status**: Implemented

**Input**: User description: "COFFEE の隠しコマンドを実装したい"（隠し要素の案 5：タイトルの隠しコマンド）

## Clarifications

### Session 2026-10-24

- Q: どこで打つか？ → A: タイトル画面で、キーボードの C・O・F・F・E・E を順に打つ
- Q: 何が起きるか？ → A: どのキャラも、プレイ中はカフェオレ色の豆で描く。性能は変えない。もう一度打つと元に戻る。オン・オフは保存して、開き直しても続く
- Q: 色は？ → A: 3 案（A カフェオレ色／B ミルクの渦／C ミルクの泡のせ）から A：豆全体をミルクの入った明るい茶色（#c49a6c）にする

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: タイトル画面で `COFFEE` と打つと、カフェオレ色のオン・オフを切り替え、「隠しコマンド！ 豆がカフェオレ色になった」（オフにしたときは「カフェオレ色をやめた」）と知らせなければならない。
- **FR-002**: オンのとき、プレイ中の豆（プレイヤー）の色と割れ目の色をカフェオレ色にしなければならない。速さ・カフェインなどの性能は変えない。
- **FR-003**: オン・オフは保存し、ゲームを開き直しても続かなければならない。保存できない環境では、そのときだけ効けばよい。
- **FR-004**: 打つ文字・知らせの文・色は設定ファイル（`secrets.cafeAuLait`）で変えられる（憲法 III）。

## Assumptions

- キャラ選択画面の豆の色は変えない（キャラ係の受け持ち。変えるときはお願いする）。
