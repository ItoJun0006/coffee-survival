# Feature Specification: 最初の攻撃を 3 つから選ぶ

**Feature Branch**: `032-start-weapon-choice`

**Created**: 2026-10-23

**Status**: Implemented

**Input**: User description: "初期の武器をマシンガンにせずに、ゲーム開始時に 3 種類から選択する仕様にしたい"

## Clarifications

### Session 2026-10-23

- Q: 3 つの候補はどう決めるか？ → A: 毎回、9 種類の攻撃（豆マシンガン・ミル・マグ・ドリップ・スチーム・こぼれ珈琲・アイス・エスプレッソ・ショックウェーブ）からランダムに 3 つ
- Q: 最初からショットガンを持つ「散弾ロブスタ」は？ → A: 選ばず、今までどおりショットガンで始める（キャラの個性のため）
- Q: 選ぶ画面は？ → A: キャラ選択のあと、プレイが始まった瞬間に、レベルアップと同じカード 3 枚の画面で選ぶ（新しい絵は作らない）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 最初の攻撃を選んで始める（Priority: P1）

プレイを始めると、ランダムな 3 つの攻撃のカードが出る。1 つ選ぶと、その攻撃（Lv 1）だけを持ってプレイが始まる。毎回ちがう攻撃から始められるので、遊ぶたびに始まり方が変わる。

**Independent Test**: キャラを選んでプレイを始め、カードが 3 枚出ること、選んだ攻撃だけを持って始まることで確認できる。

**Acceptance Scenarios**:

1. **Given** キャラ選択画面, **When** キャラを決めてプレイを始める, **Then** 時間が止まった状態で、ちがう 3 つの攻撃のカードが出る
2. **Given** カードが出ている, **When** 1 つ選ぶ（クリック・数字キー・左右キーと決定）, **Then** その攻撃 Lv 1 だけを持って、0:00 からプレイが始まる
3. **Given** 散弾ロブスタ, **When** プレイを始める, **Then** カードは出ず、ショットガンで始まる
4. **Given** やられた・クリアしたあと, **When** やり直す, **Then** またカードが出る（候補は引き直す）

### Edge Cases

- エクストラステージ（011）は、1 面から持っていく攻撃を選ぶ今の決まりのまま。カードは出さない。
- 確認用の `?weapons=`・`?level=` を付けたときは、カードを出さず、今までどおり豆マシンガンで始める（確認の手順を変えないため）。
- ピーベリー・こーひー3兄弟・ダイスケ豆も、ほかのキャラと同じく 3 つから選ぶ。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 1 面のプレイを始めるとき、9 種類の攻撃からランダムに選んだちがう 3 つのカードを出し、選んだ攻撃 Lv 1 だけを持って始めなければならない。
- **FR-002**: カードが出ている間は、プレイの時間・敵・カフェインは止まっていなければならない。
- **FR-003**: キャラに最初の攻撃が決まっているとき（散弾ロブスタ）は、カードを出さず、その攻撃で始めなければならない。
- **FR-004**: カードの画面は、レベルアップの画面と同じ見た目で、見出しを「最初の攻撃」にする。
- **FR-005**: 候補の数は設定ファイルで変えられる（憲法 III。`weaponLevels.startChoices`）。

## Assumptions

- 今まで豆マシンガンで始まる前提だった仕様（001 など）は、この仕様が上書きする。
