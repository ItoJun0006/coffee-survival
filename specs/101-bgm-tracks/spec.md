## 曲の一覧

| id | 名前 | 雰囲気 | テンポ | ひと回り |
|---|---|---|---|---|
| `normal` | いつもの一杯 | こもったローファイ・ジャズ。最初から使える | 72 | 約 13 秒（4 小節） |
| `morningBlend` | モーニングブレンド | 朝の光のような、明るく軽いローファイ。口笛のメロディー | 80 | 48 秒（16 小節） |
| `midnightDrip` | 真夜中のハンドドリップ | 雨の夜にしっとり。ゆっくりのピアノと鉄琴 | 64 | 60 秒（16 小節） |

名前・雰囲気・並び順は `CONFIG.audio.music[id].name`・`.mood`・`CONFIG.audio.tracks`。

## メインが使うもの（約束ごと）

- `CONFIG.audio.tracks`：選べる曲の id の並び。先頭の `normal` は最初から使える
- `CONFIG.audio.music[id].name` / `.mood`：画面に出す名前と一言
- `sound.setTrack(id)`：普段に流す曲を選ぶ。流れている途中なら、次の小節の頭から 2.5 秒かけて重ねながら切り替わる。ボスの間に選んだときは、ボスのあとから使われる。知らない id と `boss` は無視する
- `sound.track`：今選んでいる曲の id
- 買ったかどうか・選んだ曲の保存は、メインが持つ（音楽係は保存しない）。起動したときに保存してある曲を `sound.setTrack(id)` で渡す

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 買った曲に切り替える（Priority: P1）

豆コインで曲を買い、ポーズメニューで選ぶと、プレイ中の曲がなめらかに切り替わる（買う・選ぶ画面はメイン）。

**Independent Test**: `sound.setTrack('morningBlend')` を呼び、次の小節の頭から重ねながら切り替わり、エラーが出ないことで確かめる。

### User Story 2 - どの曲でもボスで切り替わる（Priority: P2）

どの曲を選んでいても、ボスが出るとボスの曲へ重ねながら移り、やり直すと選んでいる曲に戻る。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 新しい 3 曲を足す。今の曲と同じく、音楽ファイルを使わず Web Audio でその場で組み立てる
- **FR-002**: 新しい 3 曲は、小節のつなぎ目・ひと回りのつなぎ目で無音にならない
- **FR-003**: 曲の切り替え（曲を選び直したとき・普通 ⇔ ボス）は、次の小節の頭から `crossfadeSec`（2.5 秒）かけて重ねながら移る
- **FR-004**: 「いつもの一杯」とボスの曲の音は変えない（作り直しは仕様 100）
- **FR-005**: 曲の案は `candidates/` に音声ファイルで置き、ユーザーに聞いてもらってから決める

## Success Criteria *(mandatory)*

- **SC-001**: 新しい 3 曲を 0.25 秒ごとに測ったとき、曲の間（ボスへ移る前）に、普段の 1/4 より小さくなる瞬間がない（2026-10-24 に確認：3 曲とも 0 回。いつもの一杯は 3.3 秒ごとに 1/4 を下回る）
- **SC-002**: 実際のゲームで、曲の切り替え → ポーズ → ボス → ボス中に曲を選ぶ → ゲームオーバー → やり直し を通して、コンソールにエラーが出ない（2026-10-24 に確認）
