# Feature Specification: 攻撃の絵を薄くする設定

**Feature Branch**: `035-weapon-effect-opacity`

**Created**: 2026-10-23

**Status**: Implemented

**Input**: User description: "武器エフェクトの透明度を下げる機能（specs/ideas.md の 11、バックログ B028）"

## Clarifications

### Session 2026-10-23

- Q: 濃さはどう切り替えるか？ → A: 4 段階（100%・75%・50%・25%）を順に切り替える
- Q: 薄くするのはどこまでか？ → A: 攻撃の絵すべて（弾・刃・水たまり・光・残像・光る縁・湯気・しぶきなど）
- Q: 設定を変える場所は？ → A: ポーズメニュー（「音楽の音量」の下）
- Q: ポーズメニューでの見せ方は？ → A: 3 案（音楽の音量と同じ「◀ 50% ▶」／4 つの四角の目盛り／「◀ 50% ▶」＋弾の見本）から「◀ 50% ▶」の形。見本は描かず、この段を選んでいる間はメニューの後ろのゲーム画面を暗くしすぎないようにして、変えた濃さをその場でゲーム画面で確かめられるようにする

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 攻撃が重なっても敵や豆が見える（Priority: P1）

攻撃が増えて画面がにぎやかになったとき、ポーズメニューで「攻撃の見え方」を下げると、攻撃の絵がすべて薄くなり、後ろの敵・豆・経験値の粒が見やすくなる。

**Why this priority**: MAX の光や残像が重なると、敵や豆が見えなくなるため。この機能の中心。

**Independent Test**: 攻撃を 3 つ MAX にして敵が多い場面でポーズし、「攻撃の見え方」を 50% にして再開したとき、攻撃の絵がすべて半分の濃さになり、敵・豆・粒・プレイヤーの濃さは変わらないことで確認できる。

**Acceptance Scenarios**:

1. **Given** ポーズ中, **When** 「攻撃の見え方」を選んで ←→ を押す, **Then** 後ろのゲーム画面が明るく見えるようになり、100% → 75% → 50% → 25% と切り替わるたびに、ゲーム画面の攻撃の濃さがその場で変わる（25% で → を押しても 25% のまま、100% で ← を押しても 100% のまま）。左右の矢印をクリックしても変わる
2. **Given** 攻撃の見え方が 50%, **When** 遊ぶ, **Then** 持っているすべての攻撃の絵（弾・刃・水たまり・光・残像・光る縁など）が、100% のときの半分の濃さで描かれる
3. **Given** 攻撃の見え方が 50%, **When** 遊ぶ, **Then** 敵・ボス・豆・経験値の粒・プレイヤー・撃破のエフェクトの濃さは変わらない
4. **Given** 攻撃の見え方を 25% にした, **When** ページを開き直す, **Then** 25% のまま
5. **Given** 攻撃の見え方が 25%, **When** 遊ぶ, **Then** 攻撃の当たり方・強さは変わらない（見た目だけ）

---

### Edge Cases

- 一度も変えていないときは 100%（今と同じ見た目）。
- 攻撃の絵の中で、もともと半透明の部分（光・湯気など）は、その濃さにさらに設定の割合をかける（例：もともと 50% の湯気は、設定 50% で 25%）。
- 攻撃の絵どうしが重なったところは、重なった絵ごとまとめて薄くする（1 つずつ薄くして重ねると、重なりだけ濃く見えるため）。
- ドット絵の層（008）の縁取りは、薄くした結果に合わせて付く（薄い攻撃には縁取りが付かないことがある）。
- エクストラステージ（011）でも同じ設定が効く。
- 敵 150 体・MAX の攻撃 3 つの場面で、設定を 100% 以外にしても 60fps を保つ。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: ポーズメニューの「音楽の音量」の下に「攻撃の見え方」を足さなければならない。←→ キー・左右の矢印のクリックで、100%・75%・50%・25% の 4 段階を切り替える。
- **FR-002**: 攻撃の見え方は、持っているすべての攻撃の絵（敵の下に描くものと上に描くもの、Lv の見た目・MAX の見た目を含む）を、まとめてその割合の濃さで描かなければならない。
- **FR-003**: 攻撃以外の絵（敵・ボス・豆・経験値の粒・プレイヤー・撃破のエフェクト・背景・文字）の濃さは変えてはならない。
- **FR-004**: 攻撃の見え方はブラウザに保存し、ページを開き直しても残さなければならない（音楽の音量と同じ扱い）。
- **FR-005**: 攻撃の見え方は見た目だけを変え、当たる範囲・強さ・動きを変えてはならない。
- **FR-006**: 段階の値・初期値は設定ファイルで変えられなければならない（憲法 III）。
- **FR-007**: ポーズメニューの「攻撃の見え方」の段は、音楽の音量と同じく「攻撃の見え方 ◀ 50% ▶」と書かなければならない。この段を選んでいる間は、メニューの後ろを暗くする濃さを下げ（ふだんの 0.6 から 0.15）、←→ で変えた攻撃の濃さが、後ろのゲーム画面にその場で見えるようにする。

### Key Entities

- **攻撃の見え方**：100%・75%・50%・25% のどれか。ブラウザに保存する

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 攻撃の見え方 50% のとき、攻撃の絵の濃さが 100% のときの半分になり、攻撃以外の絵の濃さは変わらない。
- **SC-002**: ポーズメニューから 2 回以内の操作で、どの段階にも変えられる（今の段階から ←→）。
- **SC-003**: 敵 150 体・MAX の攻撃 3 つの場面で、どの段階でも 1 秒間に 60 回の画面更新を保つ。

- 設定はポーズメニューだけに置く。タイトル画面には置かない。
