# Feature Specification: 隠し要素「横切るジャコウネコ」

**Feature Branch**: `lite_enemy_cat`

**Created**: 2026-11-05

**Status**: Implemented（数値は初期案。コピ・ルアクの条件はキャラ係が足す）

**Input**: メインからの依頼（ユーザーの指示）："プレイ中に、まれに猫（ジャコウネコ）が画面を走り抜ける。追いかけて触ると、豆コインがどっさりもらえる"

## Clarifications

### Session 2026-11-05

- Q: 出る確率と時間帯は？ → A: 毎分 3%（1:00・2:00 … の毎分に抽選。10 分で 1 回以上出るのは約 26%。1 回のプレイで 2 回出ることもある）。ボスが出ている間は出ない。エクストラステージでも同じ
- Q: 逃げる速さは？ → A: 180（プレイヤーは 220）。気づいてすぐ追えば追いつける
- Q: もらえる豆コインは？ → A: 50 枚
- Q: コピ・ルアク（029）の解放につなげるか？ → A: プレイをまたいで 3 回触ると、コピ・ルアクの条件（`catTouches`）を満たす。条件そのものはキャラ係が足す
- Q: 見た目は？ → A: 3 案（A 本物のジャコウネコ寄り／B 珈琲色で豆をくわえる／C 夜の黒猫と金のきらめき）から A に決めた（`specs/proposals/2026-11-05-jaco-cat/jaco-cat-abc.png`）。灰茶の細い体に黒い斑点、目のまわりの黒い仮面、しま模様の長いしっぽ
- Q: 出たときに知らせるか？ → A: 知らせる。「何かが横切った…！」「ジャコウネコだ！ 追いかけて触ろう」。触ったら「ジャコウネコに触れた！」「豆コイン +50」

## User Scenarios & Testing *(mandatory)*

### User Story 1 - まれに横切る猫を追いかけて触る（Priority: P1）

**Acceptance Scenarios**:

1. **Given** プレイ中, **When** 毎分の抽選（3%）に当たる, **Then** 知らせが出て、画面の外からプレイヤーの近くを通って反対側へ、ジャコウネコがまっすぐ走り抜ける
2. **Given** 猫が走っている, **When** プレイヤーが触れる, **Then** 豆コインが 50 枚入り、知らせが出て、猫は消える
3. **Given** 猫が走っている, **When** 触れないまま走り抜ける, **Then** 猫は画面の外に出て消える
4. **Given** プレイをまたいで 3 回触った, **When** 3 回目に触る, **Then** コピ・ルアクの条件 `catTouches` を満たす（キャラ係が条件を足したら仕入れられるようになる）
5. **Given** 初めて触った, **When** 実績の画面を見る, **Then** 「横切るジャコウネコ」が達成になる（`secret-cat`。041）

### Edge Cases

- 猫は敵ではない。攻撃は当たらず、触れてもカフェインは減らない。
- 猫が走っている間は、次の猫は出ない。
- ボスが出ている間は抽選しても出ない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 毎分（1:00 から）、`jacoCat.chancePerMin` の確率で猫を出さなければならない。猫が走っている間とボスが出ている間は出さない。
- **FR-002**: 猫は、画面の外（プレイヤーから画面の対角線の半分より遠く）から、プレイヤーから最大 `passOffset`（160）ずれた所を通って、反対側の画面の外まで、速さ 180 でまっすぐ走り、走り終えたら消える。
- **FR-003**: 出たときと触ったときに、知らせを出さなければならない。
- **FR-004**: 触ると、豆コインを `jacoCat.coins`（50）枚渡し（`addCoins`）、実績 `secret-cat` を解放し、触った回数をプレイをまたいで数える（解放の印 `cat-touch-1`〜`cat-touch-3`）。今回が何回目か（3 まで）で、条件 `catTouches` を調べる（`#checkUnlocks('catTouches', n)`）。
- **FR-005**: 確認用に、`?cat` を付けて開くと、3 秒後に必ず猫が出る。
- **FR-006**: 数値・色・文言は設定ファイル（`jacoCat`）で変えられる（憲法 III）。

## Assumptions

- 確率・速さ・豆コインの数は初期案（`specs/backlog/playtest.md` の PE08）。
- コピ・ルアク（029）はまだ仕様が決まっていない。キャラ係が条件 `{ type: 'catTouches', count: 3 }` と、`#checkUnlocks` の判定 `catTouches: () => value >= r.count` を足す。
