# Feature Specification: 実績の画面で、隠し要素の解放の条件を見せる

**Feature Branch**: `feature/041-achievements`

**Created**: 2026-10-28

**Status**: Implemented

**Input**: User description: "実績画面を作って、何をしたら隠し要素が解放されるかわかるようにしたい。『3 分間無傷』のようなコメントと共に"

## Clarifications

### Session 2026-10-28

- Q: どこから入るか？ → A: タイトル（右下の「★ 実績（A キー）」）とポーズメニュー（「実績」）の両方
- Q: まだのものはどう見せるか？ → A: 名前は「？？？」、条件は見せる
- Q: 見た目は？ → A: 3 案（A 黒板の一覧／B スタンプカード／C メダルの額）から A
- Q: 隠しコマンドの条件の文は？ → A: 答えを書くと隠しにならないので、「タイトル画面で、この店の看板の飲み物を英語で打つ」のように遠回しにする（メインの判断）

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: タイトルとポーズメニューから、実績の画面を開けなければならない。Esc などで、開いた元の画面に戻る。ポーズから開いたときは、プレイは止まったまま。
- **FR-002**: 実績の画面は、黒板の一覧で、隠し要素ごとに★（達成）か☆（まだ）、名前、条件の文を出す。達成したものは、右にごほうびも出す。まだのものは名前を「？？？」にする。上に「達成した数 / 全部の数」を出す。
- **FR-003**: 載せる隠し要素（2026-10-28 時点）：椿三輪・カフェオレの合言葉（COFFEE）・まどろみ宝竜・豆の証・横切るジャコウネコ・金色の羊（条件「3 分間無傷」）。
- **FR-004**: 達成したかは、それぞれの仕組みが残す記録で調べる（解放の印 `unlock(id)`・豆の証の数）。COFFEE を初めて打ったときは `secret-coffee` の印を付ける。猫と金色の羊は、敵係が見つけたときに `secret-cat`・`secret-golden-sheep` の印を付ける。
- **FR-005**: 隠し要素・文・色は設定ファイル（`achievements`）で足したり変えたりできる（憲法 III）。
