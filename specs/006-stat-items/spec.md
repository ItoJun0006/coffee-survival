# Feature Specification: ステータス強化アイテムを追加する

**Feature Branch**: `006-stat-items`

**Created**: 2026-10-20

**Status**: Draft

**Input**: User description: "武器以外にステータス強化アイテムを追加（武器の弾の大きさや発生頻度を強化できる）"

## Clarifications

### Session 2026-10-20

- Q: 「弾の大きさ」「発生頻度」のほかにどんなアイテムを入れるか？ いくつ持てるか？ → A: 範囲アップ（弾の大きさを含む）・発生頻度アップ・攻撃力アップ・経験値アップの 4 種類。持てるのは 2 種類まで
- Q: アイテムの見た目（アイコン）はどうするか？ → A: 3 案（珈琲道具／カップ・ドリンク／シンボル）から、範囲アップ＝XL のマグカップ、発生頻度アップ＝ドリッパー、攻撃力アップ＝計量スプーン、経験値アップ＝角砂糖を選んだ

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 攻撃全体を強くするアイテムを選ぶ（Priority: P1）

レベルアップの候補に、攻撃（武器）だけでなく「ステータス強化アイテム」も出てくる。アイテムは特定の攻撃ではなく、持っている攻撃すべてに効く。たとえば「範囲アップ」を選ぶと、すべての攻撃の弾や範囲が大きくなる。持てるアイテムは 4 種類のうち 2 種類までなので、どれを選ぶかが作戦になる。

**Why this priority**: 攻撃を増やすか、アイテムで全体を底上げするかの選び方が生まれ、作戦の幅が広がるから。

**Independent Test**: 攻撃を 3 つ持った状態で「範囲アップ」を選び、3 つすべての弾や範囲が大きくなったかで確認できる。

**Acceptance Scenarios**:

1. **Given** レベルが上がった, **When** 候補が 3 つ出る, **Then** 攻撃とアイテムが混ざって出ることがあり、アイテムのカードは攻撃のカードと見分けられる
2. **Given** 攻撃を 3 つ持っている, **When** 「範囲アップ」を選ぶ, **Then** 3 つすべての弾・範囲が大きくなり、敵に当たる範囲も広がる
3. **Given** 「発生頻度アップ」を選んだ, **When** 攻撃が出る, **Then** すべての攻撃の間隔が短くなる
4. **Given** 「攻撃力アップ」を選んだ, **When** 攻撃が当たる, **Then** すべての攻撃のダメージが上がる
5. **Given** 「経験値アップ」を選んだ, **When** 経験値の粒を拾う, **Then** 入る経験値が増える
6. **Given** 同じアイテムを 2 回目以降に選んだ, **When** 選ぶ, **Then** そのアイテムの効果が 1 段階強くなる。最大 Lv 8 まで（007）
7. **Given** アイテムを 2 種類持っている, **When** レベルが上がる, **Then** まだ持っていないアイテムは候補に出ず、持っている 2 種類の強化だけが出る
8. **Given** あるアイテムが Lv 8, **When** レベルが上がる, **Then** そのアイテムは候補に出てこない

---

### User Story 2 - 今の強さを確かめる（Priority: P2）

持っているアイテムと、その Lv を画面で確かめられる。

**Why this priority**: 何を選んできたかが分からないと、次に何を選ぶか決めにくい。P1 のアイテムができてからでよい。

**Independent Test**: アイテムを 2 種類選んだあと、画面左上の一覧に 2 種類とそれぞれの Lv が出ているかで確認できる。

**Acceptance Scenarios**:

1. **Given** アイテムを選んだ, **When** プレイ中に画面を見る, **Then** 攻撃の一覧とは分けて、「アイテム 1/2」と、持っているアイテムとその Lv が表示されている

---

### Edge Cases

- 範囲アップで大きくなった弾や範囲が、画面を覆いつくすほど大きくならない（Lv 8 で 1.7 倍まで）。
- 「発生頻度アップ」と、キャラの攻撃間隔の倍率（深煎り ×1.3 など）、攻撃自体の強化（001 の FR-023）が重なっても、間隔は元の 0.3 倍より短くならない。
- 持っている攻撃とアイテムがすべて Lv 8 になったあとは、001 の FR-021 のとおり「カフェインを全回復」「攻撃力 +10%」から選ぶ。
- アイテムを先に選んでから手に入れた攻撃にも、そのときからアイテムの効果が効く。
- 経験値アップで経験値が小数になっても、レベルの計算は正しく行う。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: レベルアップの候補（001 の FR-021）に、攻撃とあわせてステータス強化アイテムも入れなければならない。候補は攻撃とアイテムを区別せずに、ランダムに 3 つ選ぶ。
- **FR-002**: アイテムは持っているすべての攻撃に効き、あとから手に入れた攻撃にも効かなければならない。
- **FR-003**: アイテムは Lv 1〜8 で、同じアイテムを選ぶたびに 1 段階強くなる。Lv 8 になったら候補に出さない（007）。
- **FR-004**: アイテムは次の 4 種類とする。1 段階ごとの効果の値は初期案で、遊んで調整する。

| アイテム | 効果（1 段階ごと） | Lv 8 のとき |
| --- | --- | --- |
| 範囲アップ | すべての弾・範囲（弾の大きさ、水たまりやハートの広さ、刃や衝撃波の大きさなど）が +10% 大きくなる | ×1.7 |
| 発生頻度アップ | すべての攻撃の間隔が 6% 短くなる | ×0.58 |
| 攻撃力アップ | すべての攻撃のダメージが +10% 上がる | ×1.7 |
| 経験値アップ | 経験値の粒から入る経験値が +15% 増える | ×2.05 |

- **FR-005**: 持てるアイテムは 2 種類までとしなければならない（001 の FR-025）。
- **FR-006**: アイテムのカードは、攻撃のカードと色や印で見分けられなければならない。カードには、名前・効果・「NEW」か「Lv 2 → 3」を表示する。
- **FR-007**: 画面左上に、持っているアイテムとその Lv を、攻撃の一覧とは分けて表示しなければならない。
- **FR-008**: 範囲アップで大きさを変えたときは、見た目と当たる範囲の両方を同じ割合で大きくしなければならない。敵を探す距離（射程）や、弾が飛ぶ距離は変えない。
- **FR-009**: 攻撃の間隔は、どんなに強化が重なっても、元の間隔の 0.3 倍より短くしてはならない。
- **FR-010**: アイテムごとに、珈琲にちなんだアイコンを付けなければならない。アイコンはレベルアップのカードと、画面左上のアイテムの一覧に表示する。

| アイテム | アイコン | 見た目 |
| --- | --- | --- |
| 範囲アップ | XL のマグカップ | 湯気の立つ大きなマグに「XL」の文字。まわりに広がる線 |
| 発生頻度アップ | ドリッパー | ドリッパーから、しずくが次々に落ちる |
| 攻撃力アップ | 計量スプーン | 焙煎豆を山盛りにしたスプーン。まわりにオレンジの火花 |
| 経験値アップ | 角砂糖 | 積み上げた角砂糖。まわりに金色のきらめき |

- **FR-011**: アイコンは、経験値の粒・珈琲豆・敵と見間違えない色と形にしなければならない（例：攻撃力アップのスプーンに、経験値の粒と同じ金色の丸を入れない）。

### Key Entities

- **ステータス強化アイテム**：名前、効果の種類（範囲・頻度・攻撃力・経験値）、1 段階ごとの効果の値、Lv（1〜5）
- **攻撃**：001 の攻撃に、アイテムの効果がかかる

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 「範囲アップ」を Lv 8 にすると、すべての攻撃の当たる範囲が 1.7 倍になっている。
- **SC-002**: 「発生頻度アップ」を Lv 8 にすると、すべての攻撃の間隔が 0.58 倍になっている（ほかの強化と重ねても 0.3 倍より短くならない）。
- **SC-003**: 10 回遊んだうち、選んだアイテムの組み合わせが 3 通り以上ある（どれか 1 つが強すぎない）。

## Assumptions

- アイテムはマップに落ちるものではなく、レベルアップの候補として選ぶものとする（武器と同じ選び方）。
- 攻撃の種類（11 種類）は変えない。
- アイテムの効果の値は、設定ファイルにまとめる（憲法 III）。
