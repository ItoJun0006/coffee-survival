# Feature Specification: レベルアップ画面の見た目を良くする

**Feature Branch**: `015-levelup-screen`

**Created**: 2026-10-22

**Status**: Implemented

**Input**: User description: "レベルアップ画面の見た目を追加します。攻撃のアイコン・カードのデザイン・出てくるときの演出の 3 つを足す"

## Clarifications

### Session 2026-10-22

- Q: レベルアップ画面に何を足すか？ → A: 攻撃のアイコン、カードのデザイン、出てくるときの演出の 3 つすべて
- Q: 見た目はどう決めるか？ → A: 3 つの要素それぞれに 3 案を作り、画像で見比べて選ぶ（CLAUDE.md）
- Q: 攻撃のアイコンの見せ方は？ → A: 3 案（絵だけ／属性の色の丸いバッジ／属性の色の枠のタイル）から「絵だけ」（強化アイテムのアイコンと同じ見せ方）
- Q: カードのデザインは？ → A: 3 案（黒板のメニュー／伝票／麻袋）から「黒板のメニュー」
- Q: 出てくるときの動きは？ → A: 3 案（ふわっと浮かび上がる／めくって表に返す／上から落ちて弾む）から「めくって表に返す」

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 攻撃のカードもひと目で何か分かる（Priority: P1）

攻撃のカードにも、強化アイテムと同じように珈琲にちなんだアイコンが付き、名前を読まなくてもどの攻撃か分かる。画面左上の攻撃の一覧にも同じアイコンが出る。

**Why this priority**: 今は攻撃のカードだけ文字しかなく、カードの中央が空いて見える。候補を選ぶたびに見る部分で、効果が一番大きい。

**Independent Test**: レベルアップの候補に攻撃を出し、10 種類それぞれのカードにアイコンが出ること、左上の一覧にも同じアイコンが出ることで確認できる。

**Acceptance Scenarios**:

1. **Given** レベルアップの候補に攻撃がある, **When** 画面を見る, **Then** 攻撃のカードに、その攻撃のアイコンが、強化アイテムのアイコンと同じ大きさ・位置で出ている
2. **Given** 攻撃を持っている, **When** プレイ中に左上の一覧を見る, **Then** 攻撃の名前の左に、同じアイコンが小さく出ている
3. **Given** 10 種類の攻撃, **When** アイコンを並べる, **Then** どれも違う形で見分けられ、強化アイテムのアイコン（XL マグ・ドリッパー・計量スプーン・角砂糖）とも見分けられる

---

### User Story 2 - カードが珈琲店らしく、読みやすい（Priority: P2）

カードの地が不透明になり、珈琲店にちなんだ枠と地で描かれる。種類（攻撃・強化アイテム・ボーナスなど）、属性（熱い・冷たい）、NEW・強化の段階・MAX がひと目で分かる。

**Why this priority**: 今のカードは地が薄く、後ろの敵や豆が透けて文字が読みにくい。P1 のアイコンが入る土台になる。

**Independent Test**: 敵が多い場面でレベルアップの画面を開き、カードの後ろが透けず、文字がすべて読めることで確認できる。

**Acceptance Scenarios**:

1. **Given** 敵が多い場面, **When** レベルアップの画面が開く, **Then** カードの後ろの絵は透けず、名前・説明・段階がすべて読める
2. **Given** 攻撃・強化アイテム・ボーナス・レア強化・持っていく攻撃のカード, **When** 並べる, **Then** 種類ごとに枠や地の色で見分けられる
3. **Given** 熱い・冷たい攻撃のカード, **When** 見る, **Then** 属性が色や印で分かる
4. **Given** 次で MAX になる強化のカード, **When** 見る, **Then** ほかの段階と違う特別な見た目（例：金の縁）になっている
5. **Given** 選んでいるカード, **When** ←→ で選ぶ, **Then** 選んでいるカードがはっきり分かる

---

### User Story 3 - 画面が開くときに気持ちよく出てくる（Priority: P3）

レベルアップの画面が開くとき、カードが順に出てきて、見出しに飾りが付く。選んだカードは少し強調される。

**Why this priority**: レベルアップの手応えを強めるため。遊びには影響しないので最後でよい。

**Independent Test**: レベルアップの画面を開き、カードが順に出てくること、決定するまでの操作が今と同じ速さでできることで確認できる。

**Acceptance Scenarios**:

1. **Given** レベルが上がった, **When** 画面が開く, **Then** カードが 1 枚ずつ順に出てきて、0.5 秒以内にすべて出そろう
2. **Given** カードが出てくる途中, **When** キーやクリックで決定する, **Then** 待たずに決定できる（演出のせいで遅くならない）
3. **Given** 選んでいるカード, **When** 見る, **Then** 少し大きくなる・光るなどで強調される
4. **Given** 見出し（「レベル 6！」）, **When** 画面が開く, **Then** 湯気やきらめきなど珈琲らしい飾りが付く

---

### Edge Cases

- 候補が 1〜2 枚のとき（001 の FR-021）も、カードが中央にそろい、演出も同じように動く。
- 一度に何レベルも上がって続けて選ぶとき、毎回の演出が長すぎない（0.5 秒以内）。
- エクストラステージの「持っていく攻撃を 1 つ選ぶ」画面（011）と、レア強化（010）のカードも、同じデザインで崩れない。
- アイコンは、カードでは大きく（約 56px）、左上の一覧では小さく（約 18px）描いても形が分かる。
- PC の画面幅（1000px 以上）で、カードが画面からはみ出さない。
- カードとアイコンは文字・メニューと同じく、ドット絵にしない（008 の FR-004）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 攻撃 10 種類（豆マシンガン・豆ショットガン・ミル・トルネード・マグカップ投げ・ドリップの雨・スチーム噴射・こぼれ珈琲・アイス珈琲・エスプレッソ・ショット・カフェイン・ショックウェーブ）それぞれに、珈琲にちなんだアイコンを付けなければならない。アイコンは、強化アイテムのアイコン（006 の FR-010）と同じ描き方・大きさの基準で、地や枠を付けずに絵だけで描く。

| 攻撃 | アイコン |
| --- | --- |
| 豆マシンガン | 一列に飛んでいく焙煎豆と、勢いの線 |
| 豆ショットガン | 1 点から扇形に飛び散る豆と、広がる線 |
| ミル・トルネード | 手回しの珈琲ミルと、回る線 |
| マグカップ投げ | 斜めに飛ぶマグと、戻ってくる弧の矢印 |
| ドリップの雨 | 注ぎ口の細いケトルから落ちる熱いしずく |
| スチーム噴射 | ミルクピッチャーと、もこもこ吹き出す蒸気の雲 |
| こぼれ珈琲 | 倒れたカップと、湯気の立つ水たまり |
| アイス珈琲 | 氷の入ったグラスとストロー |
| エスプレッソ・ショット | 小さなカップに一直線に落ちる濃い珈琲 |
| カフェイン・ショックウェーブ | マグから広がる二重の輪と稲妻 |
- **FR-002**: 攻撃のアイコンは、レベルアップの攻撃のカードと、画面左上の攻撃の一覧に出さなければならない。
- **FR-003**: アイコンは、10 種類どうし、強化アイテムのアイコン、経験値の粒・珈琲豆と見間違えない色と形にしなければならない。
- **FR-004**: レベルアップの画面のカードは、木の枠の黒板（不透明な濃い緑の地にチョークの文字）で描かなければならない。カードの上に種類の色の帯（攻撃＝茶、強化アイテム＝緑、ボーナス＝金、持っていく攻撃＝紫、レア強化＝椿の色）を付け、種類の名前と番号を書く。
- **FR-005**: カードには、属性（「● 熱い」は橙、「● 冷たい」は青）、NEW（橙）、強化の段階（● の列）を表示し、次で MAX になるカードは金の二重の縁と金の「Lv 7 → MAX」で見せなければならない。
- **FR-006**: 画面が開くとき、カードを左から 0.08 秒おきに 1 枚ずつ、0.25 秒でめくって表に返し、0.5 秒以内に出そろえなければならない。見出しの上に、ゆらゆら立ちのぼる湯気を描く。選んでいるカードは 1.05 倍に大きくし、種類の色で光らせる。
- **FR-007**: 演出の途中でも、キー（←→・1〜3・Space・Enter）とクリックで今までどおり選んで決定できなければならない。
- **FR-008**: アイコン・カード・演出の見た目は、Clarifications で選んだ案のとおりにしなければならない。
- **FR-009**: 色・大きさ・演出の時間は、設定ファイルで変えられなければならない（憲法 III）。

### Key Entities

- **攻撃のアイコン**：攻撃ごとの絵（10 種類）
- **カード**：種類・名前・説明・属性・NEW／段階・アイコン。選んでいるかどうか
- **画面の演出**：開いてからの時間、カードごとの出る時刻

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: アイコンだけを見て、10 種類のうち 8 種類以上を名前と結び付けられる。
- **SC-002**: 敵が 150 体いる場面でも、カードの文字がすべて読める（後ろが透けない）。
- **SC-003**: 画面が開いてから 0.5 秒以内にカードが出そろい、決定までの操作は今と同じ回数・速さでできる。
- **SC-004**: レベルアップの画面を開いている間も、1 秒間に 60 回の画面更新を保つ。

## Assumptions

- カードの大きさ（220 × 240）と並び方、操作は変えない。
- アイコンは画像ファイルを使わず、強化アイテムのアイコンと同じくプログラムで描く（憲法 II）。
- 効果音は今のレベルアップの音のまま。新しい音は足さない。
