## 今の BGM を調べた結果（2026-10-22）

`src/sound.js` の BGM を、ゲームと同じ呼び出しの順（タイトル → プレイ → ポーズ → ボス → ゲームオーバー → やり直し）でヘッドレス Chromium で鳴らし、出てくる音の大きさを 0.25 秒ごとに測った。

1. **小節ごとの息つぎ**：1 小節（約 3.3 秒）の最後の 8 分音符で、音がほぼ無音になる（大きさが普段の 1/10 ほど）。和音は小節の終わりの少し前に消え、ベースも短く、最後の 8 分音符には太鼓もないため。3.3 秒ごとに「ぷつっ」と切れて聞こえる、いちばん大きな原因
2. **くり返しが短い**：4 小節（約 13 秒）で曲がひと回りし、同じ和音・同じリズムをくり返す。メロディーもないので、ひと回りごとに区切れを感じやすい
3. **ゲームオーバー・クリアで止まる**：2.5 秒で消えて無音になり、やり直すと曲の頭からになる
4. **ボスで急に変わる**：小節の頭で、テンポ（72 → 80）と和音がいっぺんに変わる。小節の数え方はそのままなので、ボスの曲の途中の和音から始まることがある
5. **問題なかったこと**：タイトル → キャラ選択 → プレイ → タイトルに戻る では曲は止まらず続く。ポーズは音量を下げるだけ。タブを裏にするとゲームも音も止まり、戻ると続きから鳴る（ゲームがポーズになるので、これは今のままでよい）。0.4 秒の処理の詰まりを起こしても、音の予約は間に合っていた

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 遊んでいる間、曲が切れずに流れる（Priority: P1）

プレイ中、小節やひと回りのつなぎ目で音がぷつっと切れず、一続きの曲として流れる。

**Independent Test**: プレイを 1 分以上続け、つなぎ目で無音の瞬間がないことを聞いて（音の大きさを測って）確かめる。

**Acceptance Scenarios**:

1. **Given** プレイ中, **When** 曲がひと回りして頭に戻る, **Then** 音が切れずにつながる
2. **Given** プレイ中, **When** 小節が変わる, **Then** 無音の瞬間がない

### User Story 2 - ボスのとき、なめらかに盛り上がる（Priority: P2）

ボスが出ると、曲が急に別物になるのではなく、なめらかに緊張感のある曲（または盛り上がり）に移る。

**Independent Test**: ボスを出し、切り替わりの前後を聞いて、ぶつ切りに聞こえないことを確かめる。

### User Story 3 - 場面が変わっても曲が切れない（Priority: P3）

タイトル・キャラ選択・プレイ・ポーズ・レベルアップ・ゲームオーバー・クリア・やり直しで、曲が不自然に止まったり頭からになったりしない（ゲームオーバー・クリアの扱いは「まだ決めること」の答えに従う）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: BGM は、小節のつなぎ目・ひと回りのつなぎ目で無音にならない
- **FR-002**: BGM は、音楽ファイルを使わず、今と同じく Web Audio でその場で組み立てる（ビルド不要・ファイルを増やさない）
- **FR-003**: 普通 → ボスの切り替えは、なめらかに移る（具体的なやり方は「まだ決めること」の答えに従う）
- **FR-004**: 場面の切り替えで曲を止めるかどうかは「まだ決めること」の答えに従う
- **FR-005**: 音量の設定（M で消音、− ＋ で BGM の音量）は今のまま使える
- **FR-006**: 曲は 3 案を 30〜60 秒の音声ファイルにして `specs/100-seamless-bgm/candidates/` に置き、ユーザーが選んでから実装する

## Success Criteria *(mandatory)*

- **SC-001**: プレイ中の BGM の音の大きさを 0.25 秒ごとに測ったとき、普段の 1/4 より小さくなる瞬間がない（今は 3.3 秒ごとに 1/10 まで下がる）
- **SC-002**: タイトル → キャラ選択 → プレイ → ポーズ → レベルアップ → ボス → ゲームオーバー → やり直し の流れで、コンソールにエラーが出ない
