# Feature Specification: 敵のビッグウェーブ

**Feature Branch**: `009-big-wave`

**Created**: 2026-10-22

**Status**: Implemented

**Input**: User description: "たまに敵のビッグウェーブがくるようにしたい。敵の量が 3 倍になる時間が 5 秒続く。バランスが悪くなりそうなら量を調整してほしい"

## Clarifications

### Session 2026-10-22

- Q: 量や回数の調整は誰が決めるか？ → A: バランスが悪くなりそうなら、こちらで調整してよい
- Q: 同時に出せる敵の上限（150 体、001 の FR-031）はどうするか？ → A: 3 分ごろから敵は上限の 150 体に届くので、上限のままだと 3 倍にしても敵が増えない。ビッグウェーブの間だけ上限を 230 体に上げる。敵が 230 体でも描画の重さはほとんど変わらないことを確かめた
- Q: 知らせ方は？ → A: 今あるレベルアップのお知らせと同じ形で「ビッグウェーブ！」と出す。新しい絵や演出は入れない（入れるときは 3 つの候補から選ぶ）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - ときどき敵が押し寄せる（Priority: P1）

遊んでいると、ときどき「ビッグウェーブ！」と知らせが出て、5 秒のあいだ敵が 3 倍の勢いで現れる。囲まれないように逃げ回るか、まとめて倒して経験値を一気に稼ぐかの山場になる。

**Why this priority**: 10 分間の流れに緩急ができ、単調にならないから。

**Independent Test**: 開始から 1:30 ごろまで遊び、知らせが出て、5 秒のあいだ敵の出る量が 3 倍になるかで確認できる。

**Acceptance Scenarios**:

1. **Given** 開始から 1:30, **When** 時間が来る, **Then** 「ビッグウェーブ！」と知らせが出て、5 秒間、敵の出る量が 3 倍になる
2. **Given** ビッグウェーブが終わった, **When** 次の時間が来る, **Then** 90〜130 秒後に次のビッグウェーブが来る
3. **Given** 敵が 150 体いる, **When** ビッグウェーブが来る, **Then** 敵は 230 体まで増える。ビッグウェーブが終わると新しい敵は 150 体を下回るまで出ない
4. **Given** ボスの出現（10:00）まで 30 秒を切った、またはボスが出ている, **When** 時間が進む, **Then** ビッグウェーブは来ない

### Edge Cases

- ポーズ中・レベルアップの選択中は、ビッグウェーブの時間も止まる。
- ビッグウェーブの途中でレベルアップの知らせが出たら、新しい知らせで上書きしてよい。
- ビッグウェーブで出る敵の種類と強さは、その時点のふつうの敵と同じ。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 最初のビッグウェーブは開始から 90 秒で来る。次からは、前のビッグウェーブの始まりから 90〜130 秒のランダムな間隔で来る。
- **FR-002**: ビッグウェーブの間は 5 秒間、敵の出る量（001 の FR-031 の、出る間隔あたりの数）を 3 倍にしなければならない。
- **FR-003**: ビッグウェーブの間は、同時に出ている敵の上限を 150 体から 230 体に上げなければならない。※2026-10-23 に、通常の上限を 200 体、ビッグウェーブの間を 280 体に変えた（エクストラステージは 250 体・330 体。060 FR-002）
- **FR-004**: ボスの出現 30 秒前からあとは、ビッグウェーブを始めない。
- **FR-005**: ビッグウェーブが始まったら、画面上部に「ビッグウェーブ！」と「眠気が押し寄せてくる…」を、レベルアップのお知らせと同じ形で表示する。
- **FR-006**: 回数・長さ・倍率・上限は設定ファイルにまとめる（憲法 III）。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 10 分間に 4〜5 回のビッグウェーブが来る。
- **SC-002**: ビッグウェーブの間も、敵 230 体で 1 フレームの処理が 16.7 ミリ秒以内に収まる。

## Assumptions

- 回数（90〜130 秒ごと）と上限（230 体）は初期案で、遊んで調整する。
