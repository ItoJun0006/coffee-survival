# Feature Specification: 全体の文字のフォントを変える

**Feature Branch**: `003-ui-font`

**Created**: 2026-10-20

**Status**: Draft

**Input**: User description: "全体の文字のフォント"

## Clarifications

### Session 2026-10-21

- Q: どんな雰囲気のフォントにするか？ → A: 5 つの候補（M PLUS Rounded 1c／Zen Maru Gothic／DotGothic16／Yusei Magic／Kaisei Decol）と組み合わせ案をゲーム画面で見比べ、Yusei Magic（マーカーの手書き風。カフェの黒板メニューのような雰囲気）を、見出しにも本文にも使う 1 種類として選んだ

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 世界観に合ったフォントで遊べる（Priority: P1）

タイトル、キャラ選択、プレイ中の表示、ポーズメニュー、レベルアップの選択画面、結果画面まで、画面に出るすべての文字が、珈琲と夜の世界観に合ったフォントでそろっている。

**Why this priority**: 今はパソコンに入っている標準のフォント（system-ui）で、パソコンによって見た目が変わり、ゲームらしさも弱い。文字はすべての画面に出るので、変えたときの効果が大きい。

**Independent Test**: 違う種類のパソコン（Windows と Mac）で同じ画面を開き、文字の見た目が同じになっているかで確認できる。

**Acceptance Scenarios**:

1. **Given** ページを開いた, **When** タイトル画面が出る, **Then** ゲーム名が手書き風のフォント（Yusei Magic）で表示される
2. **Given** どの画面でも, **When** 文字が表示される, **Then** すべて同じフォントでそろっていて、標準のフォントが混ざっていない
3. **Given** Windows と Mac, **When** 同じ画面を開く, **Then** 同じフォントで表示される
4. **Given** インターネットにつながっていない, **When** ページを開く, **Then** フォントは同じように表示される

---

### Edge Cases

- フォントの読み込みが終わる前に画面を描き始めた場合、一瞬だけ標準のフォントで出て、読み込み後に切り替わるのはよい。ただし、切り替わったときに文字の位置が大きくずれてはならない。
- フォントが読み込めなかった場合は、今の標準のフォントで遊べる。
- 数字（タイマー・カフェイン・Lv）は、桁が変わっても幅が揺れて見えないようにする。
- 長い攻撃名（カフェイン・ショックウェーブ）が、カードや一覧からはみ出さない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 画面に出るすべての文字を、ゲーム用に決めたフォントで表示しなければならない。
- **FR-002**: フォントは Yusei Magic（マーカーの手書き風）の 1 種類とし、見出しにも本文にも使う。太字が必要な所は、ブラウザが太く見せる表示で代わりにする。
- **FR-003**: フォントのファイルは、ゲームと一緒に置き（外部のサイトから読み込まない）、インターネットにつながっていなくても表示できなければならない。
- **FR-004**: フォントは、ゲームに入れて配ってよいライセンス（例：SIL Open Font License）のものだけを使わなければならない。ライセンスの文書もゲームと一緒に置く。
- **FR-005**: フォントの種類や大きさは、設定ファイルの 1 か所で変えられなければならない（憲法 III）。今のように描く場所ごとにフォント名を書かない。
- **FR-006**: 日本語（ひらがな・カタカナ・ゲームで使う漢字）と英数字のすべてが、選んだフォントで表示できなければならない。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: すべての画面（タイトル・キャラ選択・プレイ中・ポーズ・レベルアップ・結果）で、標準のフォントが 1 文字も混ざっていない。
- **SC-002**: フォントを追加しても、ページを開いてから操作できるまでが 2 秒以内のまま（001 の SC-005）。
- **SC-003**: いちばん小さい文字（11〜12px の攻撃の一覧）でも、読み間違えずに読める。

## Assumptions

- フォントのファイルはゲームの `assets/` に置く。ビルド工程は増やさない（憲法 II）。
- 日本語フォントはファイルが大きくなりやすいので、ゲームで使う文字だけに絞ったファイルを用意してもよい。
- 文字の大きさの調整（今の 11〜28px）は、フォントを変えたあとに見やすさを確かめて決め直す。
