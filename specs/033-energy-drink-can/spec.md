# Feature Specification: エナジードリンクを揺れる缶で見せる

**Feature Branch**: `033-energy-drink-can`

**Created**: 2026-10-23

**Status**: Implemented

**Input**: User description: "エナジードリンクの絵を実装したい。いまの看板のような見た目ではなく、一番左側に配置して看板の 7 割ほどのサイズで緑色の缶の見た目にしたい。揺れている感じにして欲しい。表示は『エナジードリンク！眠気を全回復！』とします"

## Clarifications

### Session 2026-10-23

- Q: 缶の見た目と揺れ方は？ → A: 3 案（A 稲妻缶・左右に傾く／B 炭酸缶・上下にぷかぷか＋泡／C ネオン缶・震えて光る）から B に決めた

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: クリエイター豆（021）のレベルアップの画面で、エナジードリンクはカード（看板）ではなく、緑の缶の絵で出さなければならない。
- **FR-002**: 缶は候補のいちばん左に置き、高さはカードの 7 割ほどにする。クリックで選べる範囲は、カード 1 枚分のままにする。
- **FR-003**: 缶は水に浮かんだように上下にぷかぷか揺れ、少し傾き、開いた口から炭酸の泡が立ちのぼる。缶には黄色い稲妻を描く。選んでいるときは缶のまわりを緑に光らせる。
- **FR-004**: 缶の下に「エナジードリンク！」「眠気を全回復！」と出す。
- **FR-005**: 大きさ・揺れ方・泡の数・色・文は設定ファイル（`levelUpScreen.drink`）で変えられる（憲法 III）。
