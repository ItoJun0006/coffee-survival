# Feature Specification: プレイヤーの速さに合わせて追いかけてくる敵

**Feature Branch**: `062-chaser-enemy`

**Created**: 2026-10-24

**Status**: Implemented（出やすさ・速さは遊んで調整する）

**Input**: User description: "自分の移動速度に合わせて速さが変動する敵が欲しい。ミル・トルネードの中に敵が入ってこないから負けづらい。だから速い敵がいたらいい"

## Clarifications

### Session 2026-10-24

- Q: 速さはどう変わるか？ → A: プレイヤーの今の動きの速さに合わせる。動いている間はその速さの 1.1 倍で追いかけ、止まっているとゆっくり近づく
- Q: ミル・トルネードなどの押し返しは効くか？ → A: 受けにくい（3 割だけ受ける）
- Q: いつ、どのくらい出るか？ → A: 1:00 からずっと出る
- Q: 名前と見た目は？ → A: 3 案（こもりうたツバメ／ねぼすけネズミ／ゆめのながれぼし）から「ゆめのながれぼし」：うす青の星に眠そうな顔で、進む向きの反対に光の尾を引く
- Q: Lv 8 のミル・トルネードの中で止まっていると、押し返し 3 割・止まっているときの速さ 70 では届かない。どう直すか？ → A: 止まっているときの速さを 110 にする（押し返しは 3 割のまま）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 逃げても、守りを固めても追いついてくる敵（Priority: P1）

1:00 を過ぎると、プレイヤーの速さに合わせて追いかけてくる敵が混ざる。逃げ回るほど速く追ってきて、ミル・トルネードの刃に当たっても少ししか押し返されないので、刃の内側まで入ってくる。ミル・トルネードの中で止まっているだけでは安全でなくなる。

**Why this priority**: ミル・トルネードの押し返しで敵が近寄れず、負けにくくなっているため。この機能の中心。

**Independent Test**: 1:00 以降に出たこの敵に向かって、走って逃げる・止まる・ミル・トルネードの中で待つ、をそれぞれ試し、速さと押し返され方が下の FR のとおりかで確かめられる。

**Acceptance Scenarios**:

1. **Given** 0:59 まで, **When** 敵が出る, **Then** この敵は出ない
2. **Given** 1:00 を過ぎた, **When** 敵が出る, **Then** ときどきこの敵が混ざる（羊の 6 分の 1 くらいの割合）
3. **Given** プレイヤーが走って逃げている, **When** この敵が追ってくる, **Then** プレイヤーの今の速さの 1.1 倍で近づき、まっすぐ逃げるだけでは振り切れない
4. **Given** プレイヤーが止まっている, **When** この敵が近づく, **Then** 止まっているときの速さ（110。羊の 70 より速い）で近づく
5. **Given** ミル・トルネードの刃がこの敵に当たる, **When** 押し返される, **Then** ふつうの敵の 3 割の強さでしか押し返されず、刃の内側まで入ってくる
6. **Given** この敵, **When** 攻撃が当たる, **Then** 体力は低めで、ほかの敵より倒しやすい

---

### Edge Cases

- プレイヤーが足どめされている（ふとんゴーストなど）ときは、今の速さが落ちるので、この敵もゆっくりになる。
- ダイスケ豆（019）が固まっている間は、プレイヤーの速さが 0 なので、この敵も止まっているときの速さで近づく。
- 速いキャラ（浅煎りなど）ほど、走っているときのこの敵も速い。
- 凍る・足どめされるは、ふつうの敵と同じく効く（凍っている間は動かない。足どめ中は遅くなる）。
- ボスには、この敵の動きは使わない。
- 手下全体の体力の倍率（061）と、時間による強さ（001 FR-036）は、ふつうの敵と同じくかかる。
- エクストラステージでも出る。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 1:00 以降、ふつうの敵の出る候補に、この敵を加えなければならない（出やすさは羊の 6 分の 1）。
- **FR-002**: この敵の速さは、毎フレーム、プレイヤーの今の動きの速さ × 1.1 と、止まっているときの速さ（110）の大きい方にしなければならない。プレイヤーの今の動きの速さは、そのフレームに実際に動いた距離から決める。
- **FR-003**: この敵は、押し返し（ミル・トルネード・スチーム噴射・ショックウェーブ・プレスなど）をふつうの敵の 3 割の強さでしか受けてはならない。
- **FR-004**: この敵の体力はほかの手下より低くし（初期案：羊と同じ 2）、経験値は羊より少し多くする（初期案：2）。
- **FR-005**: この敵の名前と見た目は眠気にちなんだものにし、速く走っていることが分かる見た目にしなければならない（憲法 IV）。見た目は 3 案を作って画像で見せ、選んでもらってから実装する（CLAUDE.md）。ほかの敵・ボス・経験値の粒・珈琲豆と見間違えないこと。
- **FR-006**: 出る時刻・出やすさ・速さの倍率・止まっているときの速さ・押し返しを受ける割合・体力・経験値は、設定ファイルで変えられなければならない（憲法 III）。

### Key Entities

- **追いかける敵**：名前、見た目、体力、経験値、出る時刻、出やすさ、速さの倍率、止まっているときの速さ、押し返しを受ける割合

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: プレイヤーが最高速度でまっすぐ逃げたとき、この敵との距離は縮まっていく（振り切れない）。
- **SC-002**: Lv 8 のミル・トルネードの中で止まっているとき、この敵は刃の内側まで入ってきて、プレイヤーに触れる。
- **SC-003**: 1:00〜10:00 に出る敵のうち、この敵は 1 割前後。

## Assumptions

- 担当は敵係（specs/031-parallel-agents/spec.md）。仕様書は敵係の番号。
- 触れたときに減るカフェインは羊と同じ（5）。
- この敵を足すことで難しくなる分は、遊んで確かめて、出やすさや速さの倍率で調整する。
