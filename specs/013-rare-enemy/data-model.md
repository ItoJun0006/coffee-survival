# Data Model: 倒すと攻撃の枠が 4 つになるレア敵

## 設定（CONFIG.rareEnemy）

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| `chance` | 0.1 | 1 回のプレイで出る確率 |
| `appearFromSec` / `appearToSec` | 240 / 420 | 出る時刻の範囲（4:00〜7:00） |
| `leaveAfterSec` | 90 | 出てから去るまでの時間 |
| `hpRate` | 25 | 体力。出た時点の羊（`enemies.sheep`）の体力の何倍か |
| `radius` | 20 | 当たる大きさ |
| `approachDist` / `fleeDist` | 600 / 350 | これより遠いと近づく／これより近いと逃げる |
| `approachSpeed` / `wanderSpeed` / `fleeSpeed` | 120 / 90 / 190 | 動く速さ（プレイヤーは 220） |
| `wanderTurnSec` | 1.2 | うろうろするときに向きを変える間隔 |
| `xp` | 30 | 倒したときに落とす経験値 |
| `contactCaffeine` | 5 | 触れたときに減るカフェイン（羊と同じ） |
| `slots` | 4 | 倒したあとの攻撃の枠 |
| `texts` | — | 名前「まくらウサギ」と、「まくらウサギが現れた！」「攻撃の枠が 4 つになった！」「まくらウサギは逃げてしまった…」 |
| `look` | — | まくらウサギの色：体 `#bfe0f2`、耳 `#d7e9f7`、耳の内側 `#9fd3e6`、縫い目 `#7fb6d2`、目 `#3c5a73`、ほっぺ `#f2a7b8`。体は半径の 2.0 × 1.3 倍の角の丸い四角、伸び縮みは ±5%。方向の印の色は体と同じ |

## ゲームの状態（Game）に足すもの

| 項目 | 内容 | 決まり |
| --- | --- | --- |
| `rareAt` | レア敵が出る時刻（秒）。出ないプレイは `null` | `reset()` で決める。エクストラステージでは `null` |
| `rare` | 今出ているレア敵 | 出たら入れ、倒れる・去ると `null`。そのあと `rareAt` も `null` |
| `weaponSlots` | そのプレイの攻撃の枠 | `reset()` で 3。倒すと 4 |

## レア敵（RareEnemy。Enemy を土台にする）

| 項目 | 内容 |
| --- | --- |
| `appearedAt` | 出た時刻。`leaveAfterSec` たったら去り始める |
| `leaving` | 去っている途中か。画面の外へ走り去り、画面の外に出たら消える。去っている途中でも、倒せば報酬を得る |
| `mode` | 近づく・うろうろ・逃げる（距離で毎フレーム決める） |
| `wanderDir` / `wanderTimer` | うろうろするときの向きと、次に向きを変えるまでの時間 |

## 状態の移り方

```text
プレイ開始 ─(10%)─▶ 出る予定あり ──4:00〜7:00──▶ 出ている ──倒す──▶ 枠 4（そのプレイの間）
           └(90%)─▶ 出ない              │            │
                                       │            └─90 秒／ボス出現─▶ 去る（知らせ）
                                       └─ボス出現（予定の時刻より前）─▶ 出ない
```
