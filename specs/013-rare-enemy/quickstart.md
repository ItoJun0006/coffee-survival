# Quickstart: レア敵を確かめる

## 準備

```bash
python3 -m http.server 8000
```

PC のブラウザ（幅 1000px 以上）で開く。ファイルを変えたあとは、強制再読み込みをする。

## 1. 出る・動く・倒す（US1）

1. `http://localhost:8000/?rare` で始める。数秒後にレア敵が現れ、知らせ・効果音・画面の端の方向の印が出る。
2. 立ち止まって見る：遠いと近づき、中くらいの距離ではうろうろし、近づくと逃げる。立ち止まったままでは 60 秒たっても倒れない（SC-002）。
3. 追いかける：攻撃 3 つ・Lv 5 前後（`?rare&level=15` など）で、30 秒以内に倒せる（SC-001）。
4. マップの角に追い詰める：壁に沿って逃げ、角で止まらない。
5. 倒す：大きめのエフェクトと効果音、「攻撃の枠が 4 つになった！」、左上が「攻撃 n/4」、経験値の粒が多めに落ちる。
6. 次のレベルアップで、まだ持っていない攻撃が候補に出て、4 つ目を手に入れられる（SC-004）。
7. ゲームオーバー後にやり直すと「攻撃 1/3」に戻る。

## 2. 去る（US2）

1. `?rare` で始め、倒さずに 90 秒待つ：レア敵が画面の外へ走り去り、「レア敵は逃げてしまった…」と出る。
2. `?rare&boss` で始める：ボスが出るとレア敵は去る。

## 3. 出る確率と時刻（SC-003）

1. 開発者ツールのコンソールで、ゲームの `reset()` を 200 回呼び、`rareAt` が `null` でない回数と、その値がすべて 240〜420 の中にあることを数える。10〜30 回なら合格。

## 4. いつもの確認

- 移動・ポーズと再開・リトライが動く。エクストラステージ（011）ではレア敵が出ない。コンソールにエラーがない。
