# Feature Specification: Lv 2・4・6 で武器の見た目が段階的に豪華になる

**Feature Branch**: `014-weapon-level-visuals`

**Created**: 2026-10-22

**Status**: Implemented

**Input**: User description: "レベルアップの武器ビジュアルも合わせて追加したい"（Lv 2・4・6 の見た目。MAX（Lv 8）だけでなく、途中の Lv でも攻撃の絵が少しずつ豪華になる）

## Clarifications

### Session 2026-10-22

- Q: どの Lv で見た目を変えるか？ → A: 特別な強化が入る Lv 2・4・6 で 1 段階ずつ変える。Lv 1 は今の見た目、Lv 8 は MAX の見た目（007・012）のまま
- Q: どの武器が対象か？ → A: 豆マシンガン・豆ショットガンと、012 の 8 種類（ミル・トルネード、マグカップ投げ、カフェイン・ショックウェーブ、ドリップの雨、スチーム噴射、こぼれ珈琲、エスプレッソ・ショット、アイス珈琲）
- Q: 段階の見た目はどれにするか？ → A: 3 つの候補（A 光が強まる、B 光る縁、C 粒が増える）を武器ごとに Lv 1・2・4・6・8 で見比べ、B「光る縁」に決めた

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 育てるほど、攻撃の見た目が少しずつ豪華になる（Priority: P1）

武器を Lv 2・4・6 と強化するたびに、攻撃の絵がひと目で分かるくらい少しずつ豪華になる。MAX（Lv 8）でいちばん大きく変わる流れの途中が見えるので、育てている手応えがある。

**Why this priority**: 今は Lv 1〜7 の見た目が同じで、強化しても絵からは育ち具合が分からないため（002 の FR-003）。

**Independent Test**: 1 種類の武器を `?weapons=<id>:1`・`:2`・`:4`・`:6`・`:8` で開き、同じ場面で見比べる。

**Acceptance Scenarios**:

1. **Given** ある武器が Lv 1, **When** 攻撃が出る, **Then** 今までどおりの見た目
2. **Given** ある武器が Lv 2・4・6, **When** 攻撃が出る, **Then** Lv が上の段階ほど豪華に見える（Lv 3・5・7 は、すぐ下の偶数 Lv と同じ段階）
3. **Given** ある武器が Lv 6, **When** Lv 8（MAX）と見比べる, **Then** MAX の方がはっきり豪華に見える（MAX の特別さを損なわない）
4. **Given** 段階の見た目, **When** 当たる範囲と見比べる, **Then** はっきりした部分は当たる範囲の中に収まっている（ぼんやりした光や粒は外に出てよい）

### Edge Cases

- 敵 150 体・同じ攻撃がたくさん出ている場面（ショックウェーブの輪、エスプレッソの線、こぼれ珈琲の水たまり）でも、1 秒間に 60 回の画面更新を保つ。
- 経験値の粒（金色の丸）・珈琲豆・敵と、段階の見た目を見間違えない。
- 床に広がる攻撃（こぼれ珈琲）の段階の見た目は、敵より下に描く。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 対象の武器は、Lv 2・4・6 で見た目の段階が 1 つずつ上がらなければならない（段階 1：Lv 2〜3、段階 2：Lv 4〜5、段階 3：Lv 6〜7）。Lv 1 は今の見た目、Lv 8 は MAX の見た目とする。
- **FR-002**: 段階の見た目は、攻撃のはっきりした部分（弾・刃・マグ・雫・水たまり・輪・線など）に重ねて描き、当たる範囲を変えてはならない。はっきり描く部分は当たる範囲の中に収める（002 の FR-005）。
- **FR-003**: 段階の色は属性で分ける。熱い攻撃は暖色と湯気、冷たい攻撃は寒色と光、属性のない攻撃は焙煎色・クリーム色（002 の FR-002）。
- **FR-004**: 段階の見た目は、MAX の見た目より控えめにしなければならない（段階 3 と MAX を見比べて、MAX がはっきり豪華に見える）。
- **FR-005**: 段階の見た目は「光る縁」とする：はっきりした部分の縁（当たる範囲の内側）に、属性の色の線を描く。線は段階ごとに明るくなり、段階 3 で太くなる（熱い：銅色→オレンジ→淡いオレンジ、冷たい：青→水色→白っぽい水色、属性なし：焙煎色→キャラメル色→淡い黄色）。見た目の候補は、対象のすべての武器に同じ考え方で付けた 3 案を、同じ場面の Lv 1・2・4・6・8 で見比べて選ぶ（CLAUDE.md の決まり）。
- **FR-006**: 色・濃さ・大きさ・数は設定ファイルに置かなければならない（憲法 III）。

### Key Entities

- **見た目の段階**：武器の Lv から決まる 0〜3 の段階（0 は Lv 1、MAX は段階ではなく MAX の見た目）
- **段階の見た目の目印**：段階の見た目を重ねる位置と大きさ。武器ごとに、はっきりした部分から決める

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 対象の武器それぞれで、Lv 1・2・4・6・8 の画面を並べたとき、遊んだ人が Lv の順に並べ替えられる。
- **SC-002**: 敵 150 体・段階 3 の武器 3 つの場面で、1 秒間に 60 回の画面更新を保つ。

## Assumptions

- 段階の見た目は、武器の形そのものは変えずに重ねて描く（形が変わるのは MAX だけ）。
- 縁の線は、012 の `src/weapons/max-fx.js` の描き方（`circle`）を使う。
- 絵はプログラムで描き、ドット絵の層（008）を通して表示する。
