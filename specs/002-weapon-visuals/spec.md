**Status**: 一部実装（FR-001・002・003・005 は 012・014・015 で実現した。FR-004「強化した直後に攻撃を一瞬光らせる」は 2026-10-24 に C で実装。バックログ B015）

**Input**: User description: "武器のビジュアル"

## Clarifications

### Session 2026-10-24

- Q: 強化した直後の光らせ方は？（FR-004。3 案：specs/002-weapon-visuals/candidates/upgrade-flash-abc.jpg） → A: C に決めた。攻撃の絵の縁（Lv 2・4・6 の見た目と同じ目印の外側）に金色の輪を付け、プレイヤーの頭の上に、その武器のアイコンと「Lv N ↑」の札が上がって消える。1.2 秒で消える。新しく手に入れたとき（Lv 1）は光らせない


### User Story 1 - どの攻撃が出ているか一目で分かる（Priority: P1）

11 種類の攻撃それぞれが、珈琲にちなんだ見た目ではっきり描き分けられている。画面がにぎやかになっても、どの攻撃が敵に当たっているかが分かる。

**Why this priority**: 今の攻撃は単純な丸や線で描かれていて、攻撃が増えると見分けにくい。選んだ攻撃が働いている手応えが、遊びの楽しさの中心だから。

**Independent Test**: 11 種類の攻撃を 1 つずつ持った状態で遊び、それぞれの攻撃を名前と結び付けて言い当てられるかで確認できる。

**Acceptance Scenarios**:

1. **Given** 豆マシンガンだけを持っている, **When** 敵に向かって撃つ, **Then** 弾は焙煎した珈琲豆の形で、飛ぶ方向に向いて回転して見える
2. **Given** アイス珈琲を持っている, **When** 氷を飛ばす, **Then** 氷のかけらは半透明の水色で、きらっと光る
3. **Given** 熱い攻撃（ドリップの雨・スチーム噴射・こぼれ珈琲・エスプレッソ）を持っている, **When** 攻撃が出る, **Then** 湯気やしずくなど「熱い」ことが分かる見た目になっている
4. **Given** すべての攻撃を持っている, **When** 敵が多い場面で遊ぶ, **Then** それぞれの攻撃の色と形が重ならず、見分けられる

---

### User Story 2 - 強化した攻撃ほど見た目も強そうになる（Priority: P2）

攻撃の Lv が上がると、見た目も少しずつ豪華になり、強くなったことが目で分かる。

**Why this priority**: レベルアップで攻撃を選ぶ遊び（001 の FR-021・FR-023）と結び付き、強化した手応えが増すから。見た目の基本（P1）ができてからでよい。

**Independent Test**: 同じ攻撃を Lv 1 と Lv 8 で並べて見比べ、違いが分かるかで確認できる。

**Acceptance Scenarios**:

1. **Given** ある攻撃が Lv 1, **When** その攻撃を Lv 8 まで強化する, **Then** 光る縁取りや残像などが加わり、Lv 1 より目立って見える
2. **Given** 攻撃を強化した, **When** 強化した直後, **Then** その攻撃が一瞬光り、強くなったことが分かる

---

### Edge Cases

- 攻撃と敵がたくさん重なっても、プレイヤーキャラが攻撃の陰に隠れて見えなくならない（攻撃はプレイヤーより目立ちすぎない）。
- 敵 150 体・攻撃 11 種類がそろった最も重い場面でも、見た目を良くしたせいでカクつかない。
- 夜が深まって画面が暗くなっても、攻撃の色が見分けられる。
- ボス戦の「まぶたの帳」（周りが真っ暗になる）の間も、プレイヤーの近くの攻撃は見える。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 11 種類の攻撃すべてに、珈琲にちなんだ専用の見た目を付けなければならない。それぞれの見た目の方針は次の表のとおり。

| 攻撃 | 見た目の方針 |
| --- | --- |
| 豆マシンガン | 回転しながら飛ぶ焙煎豆。通ったあとに細い香りの線 |
| ミル・トルネード | 珈琲ミルの刃。回ると挽いた粉が舞う |
| マグカップ投げ | 取っ手付きのマグ。回転しながら飛び、珈琲がこぼれるしぶき |
| ドリップの雨 | ドリッパーから落ちる熱いしずく。落ちた所に小さな湯気 |
| スチーム噴射 | 白い蒸気の雲が扇形に広がって消える |
| こぼれ珈琲 | 床に広がる茶色の水たまり。表面がゆらぎ、湯気が立つ |
| アイス珈琲 | 半透明の氷のかけら。凍った敵には霜が付く |
| エスプレッソ・ショット | 濃い茶色の一直線の液体。クレマ（泡）の色の縁 |
| フレンチプレス | 上から降りてくるプレスのつまみと網。押しつぶすと粉が飛び散る |
| ラテアート | 床に描かれる白いハートの模様。ゆっくり脈打つ |
| カフェイン・ショックウェーブ | 金色に光る円い衝撃波 |

- **FR-002**: 熱い攻撃は暖色と湯気、冷たい攻撃は寒色と光、と属性が見た目で分からなければならない。
- **FR-003**: 攻撃の Lv が上がるほど、見た目を豪華にしなければならない（光の縁取り・残像・大きさの変化など）。Lv 8（MAX）は Lv 1 と見比べてはっきり分かる差にする。豆マシンガンの MAX の見た目は 007 で決める。
- **FR-004**: 攻撃を強化した直後に、その攻撃を一瞬光らせなければならない。見せ方は Clarifications の C（金色の輪と「アイコン Lv N ↑」の札）。限界突破（011）の強化も同じ。金色の輪は攻撃の絵なので、攻撃の見え方（035）の濃さに合わせて薄くなる。札は文字なので薄くしない。
- **FR-005**: 攻撃の当たり判定（当たる範囲）は、見た目を変えても変えてはならない。見た目と当たる範囲がずれないようにする。

### Key Entities

- **攻撃の見た目**：攻撃の種類、属性、Lv に応じて決まる描き方

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 遊んだ人が、11 種類の攻撃のうち 9 種類以上を、見た目だけで名前と結び付けられる。
- **SC-002**: 敵 150 体・攻撃 11 種類（すべて Lv 8）の場面でも、1 秒間に 60 回画面が更新される。
- **SC-003**: Lv 1 と Lv 8 の同じ攻撃を並べたとき、遊んだ人の全員が「Lv 8 の方が強そう」と答える。

## Assumptions

- 絵は画像ファイルを使わず、今と同じようにプログラムで描く（憲法 II）。画像ファイルを使う場合は、別途決める。
- 攻撃の性能（ダメージ・範囲・間隔）は変えない。見た目だけを変える。
- 色や大きさなど調整する値は、設定ファイルにまとめる（憲法 III）。
- 豆の色は、キャラの焙煎度の色とは別にする（プレイヤーと弾を見分けるため）。
