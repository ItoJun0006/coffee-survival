# デザインの変更案（毎朝のルーティン）

実装済みのキャラ・武器・背景について、見た目を良くする変更案を毎朝作ってためておく場所。
ルーティン「珈琲サバイバル：朝のデザイン案」（毎朝 6:15）が、下の順番表から 1 日に **キャラ 1 つ・武器 1 つ・背景 1 つ** を選び、
それぞれ **3 案** の比較画像を作って、日付のフォルダ（`specs/proposals/YYYY-MM-DD/`）に置く。

- ここにある案は「候補」で、ゲームにはまだ入っていない（憲法「開発の流れ」の 4：見た目は 3 案から選んでから実装する）。
- 気に入った案があれば、その日の `README.md` を見て「〇〇の B」のように伝える。選ばれた案は、仕様書（`specs/NNN-…`）に書いてから実装する。
- いらない案のフォルダは消してよい。
