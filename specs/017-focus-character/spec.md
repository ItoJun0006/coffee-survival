# Feature Specification: 弾が 1 つだけの「一点集中」キャラ（ピーベリー）

**Feature Branch**: `017-focus-character`

**Created**: 2026-10-22

**Status**: Implemented

**Input**: User description: "武器の発射数を 1 に固定する代わりに、1 つの威力と頻度が減った分上乗せされる尖った性能のキャラを実装したい。数のない武器は変化なし。購入の値段を 1.3 倍にします。効果が適応されない武器は出現率を半分にしてください。このキャラを目玉が 1 つのデザインにします。条件は、3 種類の豆で最大強化武器を所持した状態で 1 ステージ勝利"

## Clarifications

### Session 2026-10-22

- Q: 名前は？ → A: 「ピーベリー」。実在する珈琲豆で、ふつうは 1 つの実に 2 つ入る種が、1 つだけ丸く育ったもの。「1 つに力を集める」性能と、目玉が 1 つの見た目に合う（憲法 IV）
- Q: 減った数の分は、どう上乗せするか？ → A: 時間あたりの与ダメージ（1 体に当てたとき）が、ふつうのキャラとそろうようにする。減った数を N 倍とすると、威力を N の 0.65 乗倍、攻撃の頻度を N の 0.35 乗倍にする（掛け合わせると N 倍）。3 → 1 なら威力 2.04 倍・頻度 1.47 倍。威力を多めにして、攻撃の間隔の下限（0.25 倍、006 FR-009）に届きにくくする
- Q: 数のない武器は？ → A: 変えない（こぼれ珈琲・カフェイン・ショックウェーブ・アイス珈琲）。そのかわり、このキャラのときは、これらの武器のカードがレベルアップの候補に出る割合を半分にする
- Q: 値段は？ → A: 特別なキャラでいちばん高い赤ちゃん豆（300 枚）の 1.3 倍で、390 枚
- Q: 条件は？ → A: 3 種類の豆それぞれで、Lv 8（MAX）の攻撃を持った状態で 1 面をクリアすると、仕入れられるようになる（016 FR-018）。「種類」は品種で数える（アラビカの浅煎りと中煎りは同じ 1 種類。特別なキャラはそれぞれ 1 種類）
- Q: 並べ方は？ → A: 品種「ケント」を外して空いたマスに入れる（016 の FR-022）。最後の段に、こーひー3兄弟と並べる
- Q: 見た目は？ → A: 3 案（A 大きな丸い目／B きりっとした目と太い眉／C 照準の輪の目）から、A（顔の真ん中に大きな丸い目）に決めた

### Session 2026-10-24

- Q: ピーベリーのミル・トルネードは？ → A: 刃が 1 枚になる代わりに、回る速さを「本来の刃の数」倍にする（例：本来 4 枚なら 4 倍）。威力・当たる間隔の上乗せ（FR の N^0.65・N^0.35）はそのまま。Lv 8 までの回転半分（012）も、そのまま掛かる。設定は `weapons.mill.focusSpinExp`

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 1 発に力を集めて戦う（Priority: P1）

ピーベリーを選ぶと、豆マシンガンの豆やミル・トルネードの刃など「数」のある攻撃が、いつも 1 つだけになる。そのかわり、1 つの威力が大きく、出る間隔も短い。数で囲む戦い方はできないが、狙った敵を素早く倒せる。

**Why this priority**: ほかのキャラと遊び方がはっきり違う、尖ったキャラを作るため。

**Independent Test**: ピーベリーで豆マシンガンを Lv 8 にし、豆が 1 つしか出ないこと、1 発の威力と頻度が上がっていることで確認できる。

**Acceptance Scenarios**:

1. **Given** ピーベリー, **When** 豆マシンガンが Lv 8（ふつうは豆 3 つ）, **Then** 豆は 1 つで、威力は 3 の 0.65 乗倍（約 2.04 倍）、間隔は 3 の 0.35 乗分の 1（約 0.68 倍）になる
2. **Given** ピーベリー, **When** こぼれ珈琲・ショックウェーブ・アイス珈琲を持つ, **Then** 性能はふつうのキャラと同じ
3. **Given** ピーベリー, **When** レベルアップの候補が出る, **Then** 数のない武器のカードは、ふつうの半分の割合でしか出ない
4. **Given** ふつうのキャラ, **When** 遊ぶ, **Then** 何も変わらない

---

### User Story 2 - 条件を満たして仕入れる（Priority: P2）

3 種類の豆で、MAX の攻撃を持ったまま 1 面をクリアすると、ピーベリーが仕入れられるようになり、豆コイン 390 枚で買える。

**Acceptance Scenarios**:

1. **Given** 2 種類の豆で条件を満たした, **When** 3 種類目の豆で、MAX の攻撃を持ったまま 1 面をクリアする, **Then** 「『ピーベリー』が仕入れられるようになった！」と出る
2. **Given** 同じ豆で何度もクリアした, **When** 数える, **Then** 1 種類としか数えない

### Edge Cases

- 攻撃の間隔は、上乗せしても元の 0.25 倍より短くしない（006 FR-009）。
- スチーム噴射の「吹く向き」（Lv 6 の前と後ろ）は数として扱い、前だけにする。MAX の全方向に吹く（360°）は数ではないので変えない。
- エクストラステージ（011）でも同じ。限界突破で数が増える武器はないので、上乗せは Lv 8 のときと同じ。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: キャラ「ピーベリー」を特別なキャラとして加えなければならない。性能はアラビカ中煎りと同じ。最初の攻撃は豆マシンガン。
- **FR-002**: ピーベリーのときは、攻撃の数（豆マシンガン・豆ショットガンの豆、ミル・トルネードの刃、マグカップ投げのマグ、ドリップの雨の雫、エスプレッソ・ショットの本数、スチーム噴射の吹く向き）をいつも 1 にしなければならない。
- **FR-003**: 数を 1 にした攻撃は、本来の数を N として、威力を N^0.65 倍、攻撃の間隔を N^0.35 分の 1 にしなければならない。指数は設定ファイルで変えられる（憲法 III）。
- **FR-004**: ピーベリーのときは、数のない武器（こぼれ珈琲・カフェイン・ショックウェーブ・アイス珈琲）のカードが、レベルアップの候補に出る割合を半分にしなければならない。
- **FR-005**: ピーベリーは、3 種類の品種（特別なキャラはそれぞれ 1 種類）で「Lv 8 の攻撃を持った状態で 1 面をクリア」すると仕入れられるようになり、豆コイン 390 枚で買えなければならない（016 FR-018）。条件を満たしたキャラの種類は保存する。
- **FR-006**: ピーベリーは、顔の真ん中に大きな丸い目が 1 つの見た目にしなければならない。

## Assumptions

- 指数（0.65・0.35）と値段（390 枚）は初期案で、遊んで調整する。
