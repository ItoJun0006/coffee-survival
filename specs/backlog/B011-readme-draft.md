````markdown
# 珈琲サバイバル

珈琲をテーマにしたサバイバルゲーム。PC のブラウザで遊ぶ HTML5 Canvas ゲーム。

## 構成

ビルド不要。素の JavaScript (ES Modules) と Canvas 2D で動作する。

```
index.html             エントリポイント
css/style.css          全画面表示のスタイル
src/main.js            起動処理
src/game.js            ゲームループ・描画・状態管理
src/input.js           キーボード / マウスクリック入力
src/config.js          ゲームバランス・色などの定数（調整する数値はここに集める）
src/stage.js           ステージ（1 面・エクストラステージ）の切り替え
src/characters.js      キャラ（豆の品種）の一覧と解放の条件
src/character-select.js キャラ選択画面
src/level-up-menu.js   レベルアップ・最初の攻撃選びの画面
src/progress.js        豆コイン・キャラの解放・遊んだ回数などの保存
src/records.js         自己ベスト・クリア回数の保存（records-ui.js が表示）
src/sound.js           効果音と音楽
src/entities/          プレイヤー・敵・ボス・経験値の粒などのエンティティ
src/weapons/           攻撃（豆マシンガン・ミル・トルネードなど）
assets/                画像・アイコン等
specs/                 仕様書（spec-kit）とバックログ
```

## 起動

ES Modules を使うため、ファイルを直接開くのではなくローカルサーバ経由で開く。

```bash
python3 -m http.server 8000
```

http://localhost:8000 を開く。

## 操作

| 操作 | キー |
| --- | --- |
| スタート | Space / Enter / クリック |
| キャラ選択 | ←→↑↓（WASD）で選んで Space / Enter。クリックで選び、もう一度クリックで決定。ホイールでスクロール。鍵のキャラは決定すると解放条件が出る。豆コインで買えるキャラは決定すると買える。Esc でタイトルへ |
| スキン「椿」の付け外し | キャラ選択でアラビカを選んでいるときに Q（椿の花を 3 種類そろえると使える） |
| 最初の攻撃選び | ←→ で選んで Space / Enter、1〜3 キー、またはクリック |
| 移動 | WASD / 矢印キー |
| レベルアップの攻撃選び | ←→ で選んで Space / Enter、1〜3 キー、またはクリック |
| ポーズ | Esc / P |
| 音の消音 / 解除 | M |
| 音楽の音量 | − で下げる / ＋ で上げる（ポーズメニューの「音楽の音量」でも変えられる） |
| ポーズメニューの選択 | ↑↓（W / S）で選んで Space / Enter、またはクリック |
| エクストラステージへ | 1 面のクリア画面で E。持っていく攻撃を 1 つ選ぶ |
| リトライ | Space / Enter / クリック |

## ルール

時間とともにカフェインが減っていく。マップ上の珈琲豆を拾って補給し、できるだけ長く生き延びる。

始めるときに、最初の攻撃を 3 つから 1 つ選ぶ。10 分たつと眠気の化身（ボス）が現れ、倒すと朝が来てクリア。
敵が落とす経験値の粒でレベルが上がるたびに、攻撃（最大 3 つ）か強化アイテム（最大 2 種類）を選んで強くする。それぞれ最大 Lv 8。

- **豆コイン**：1 回のプレイが終わるたびに、生き延びた時間・倒した敵の数・クリアに応じてたまる。キャラ選択で、新しい豆の品種を買うのに使う。
- **エクストラステージ**：1 面をクリアすると挑める 2 つ目のマップ。持っている攻撃を 1 つだけ（Lv はそのまま）持っていく。マップは狭く、カフェインは時間で減らず、レベルが上がると回復する。Lv 8 の先（限界突破）まで強くできることがある。
- **自己ベスト**：結果画面に、今回の生存時間・倒した敵の数・到達レベルと自己ベストが出る。タイトルには自己ベストとクリア回数が出る（エクストラステージは数えない）。

## 動作確認用の URL パラメータ

アドレスの後ろに付けて開くと、確かめたい場面からすぐ始められる。`?weapons`・`?level`・`?boss`・`?unlockAll`・`?coins` を付けて遊んだときは、自己ベストは更新されない。`?unlockAll`・`?coins` のときは、豆コインやキャラの解放も保存されない。

| パラメータ | 例 | 何が起きるか |
| --- | --- | --- |
| `?weapons=攻撃:Lv,…` | `?weapons=mill:8,drip:5` | 指定した攻撃を指定した Lv で持って始まる |
| `?level=N` | `?level=12` | レベル N から始まる |
| `?boss` | `?boss` | ボスが出る直前から始まる |
| `?maxVariant=A\|B\|C` | `?maxVariant=B` | 攻撃の MAX の見た目の案を切り替える |
| `?unlockAll` | `?unlockAll` | すべてのキャラが解放された状態で始まる |
| `?coins=N` | `?coins=500` | 豆コインを N 枚持った状態で始まる |

いくつか組み合わせてもよい（例：`?weapons=mill:8&boss`）。
````
